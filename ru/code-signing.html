Подпись и проверка файлов ClipSD

Подписаны ли файлы

Пока нет. Установщик для Windows не подписан цифровым сертификатом: платная подпись стоит денег каждый год, а бесплатная для открытых проектов ещё не оформлена. Поэтому при первом запуске Windows показывает синее окно SmartScreen. Нажмите «Подробнее», затем «Выполнить в любом случае».

Обновления программа ставит сама, но только подписанные. Описание новой версии (latest.json) подписано ключом автора (Ed25519); открытая часть ключа вшита в программу. Программа отвергает описание без верной подписи, с истёкшим сроком или с версией старее уже виденной, а скачанный файл проверяет по размеру и сумме SHA-256 из подписанного описания. Закрытый ключ хранится у автора отдельно от GitHub, поэтому даже тот, кто подменит файлы на GitHub, не сможет выдать их за обновление.

Как проверить, что файл настоящий

Рядом с каждой кнопкой скачивания на сайте указана контрольная сумма SHA-256: это отпечаток файла из 64 знаков. Если файл изменён хотя бы на один байт, отпечаток будет другим. Список сумм лежит рядом с файлами выпуска на GitHub и на сайте: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<версия>-Setup.exe -Algorithm SHA256

Linux, терминал:

sha256sum ClipSD-<версия>-linux-x86_64.tar.gz

Сравните результат с суммой на сайте. Совпало: файл тот, что выложил автор. Не совпало: не запускайте его и напишите автору.

Откуда брать файлы

Только со страницы скачивания сайта ClipSD или со страницы выпуска на GitHub: https://github.com/clipsd/clipsd/releases (откроется в новой вкладке) . Кнопки сайта ведут туда же. Сайты-сборники программ могут перепаковать установщик со своими добавками.

Исходный код

ClipSD распространяется по лицензии GNU GPL v3. Исходный код каждой версии лежит на GitHub: https://github.com/clipsd/clipsd (откроется в новой вкладке) , на странице выпуска v<версия> есть архивы исходников. Программу можно собрать самому и сравнить.

Сообщить о подозрительном файле

Если вы нашли файл с названием ClipSD, сумма которого не совпадает с сайтом, или он ведёт себя подозрительно, напишите на clipsd.app@gmail.com.

Политика подписи кода (Code signing policy)

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Бесплатную подпись кода предоставляет SignPath.io, сертификат выдан SignPath Foundation.

Статус: заявка в SignPath Foundation подана 20.11.2026. Пока её не одобрили, установщик с сайта не подписан. Версия из Microsoft Store подписана Microsoft.

Что подписывается: установщик ClipSD-<версия>-Setup.exe, запускатель ClipSD.exe, программа ClipSD-app.exe и программа удаления unins000.exe. Подпись ставится только на файлы, которые GitHub Actions собрал из исходников репозитория https://github.com/clipsd/clipsd (откроется в новой вкладке) . Библиотеки других проектов (Python, Qt и другие) лежат в установщике в том виде, в каком их выпускают их авторы, нашей подписью они не подписываются.

Кто отвечает:

  • Авторы кода и проверка чужих изменений (committers and reviewers): Сергей Дайнеко, участники организации clipsd: https://github.com/orgs/clipsd/people (откроется в новой вкладке)
  • Одобрение каждой подписи (approvers): Сергей Дайнеко, владелец организации clipsd: https://github.com/orgs/clipsd/people?query=role%3Aowner (откроется в новой вкладке)

Все участники входят в GitHub и SignPath с двухфакторной проверкой. Каждый выпуск подписывается только после ручного одобрения.

Конфиденциальность: политика конфиденциальности ClipSD. Программа сама отправляет данные только в трёх случаях:

  • страница обновлений: раз в день, выключается в настройках;
  • сервис перевода: когда вы нажимаете кнопку перевода;
  • приёмник оценок ClipSD: только когда вы сами нажимаете «Отправить» в окне оценки.

Какого издателя покажет Windows: «SignPath Foundation», а не имя автора. Сертификат выдан фонду; подпись подтверждает, что файл собран автоматически из открытого кода этого репозитория.

Как проверить подпись: щёлкните файл правой кнопкой, «Свойства», вкладка «Цифровые подписи»: в списке должен быть «SignPath Foundation». Или в PowerShell:

Get-AuthenticodeSignature .\ClipSD-<версия>-Setup.exe | Format-List Status, SignerCertificate

В строке Status должно быть Valid.
