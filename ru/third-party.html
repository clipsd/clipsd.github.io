Сторонние компоненты ClipSD

ClipSD распространяется по лицензии GNU GPL версии 3 или более поздней (GPL-3.0-or-later). Программа использует библиотеку PyQt6 с лицензией GPL-3.0, поэтому готовая сборка для Windows распространяется на условиях GNU GPL версии 3.

Полные тексты лицензий лежат на этом сайте в папке licenses: GPL-3.0, LGPL-3.0, PSF-2.0, Apache-2.0, FTL, libffi (MIT), bzip2, xz (0BSD), LLVM-exception, OFL-1.1.

Внешние программы и службы, которые ClipSD не распространяет

  • Tesseract (Apache-2.0, https://github.com/tesseract-ocr/tesseract (откроется в новой вкладке)): программа распознавания текста для Linux. Ставится отдельно, по желанию, командой системы. ClipSD запускает её как отдельную программу.
  • Распознавание текста Windows (Windows.Media.Ocr): часть Windows 10 и 11.
  • Шрифт. В Linux ClipSD один раз делает из установленного в системе шрифта Ubuntu Sans (Ubuntu Font Licence 1.0, https://canonical.com/legal/font-licence (откроется в новой вкладке)) статические начертания «ClipSD Sans» и хранит их в ~/.cache/clipsd/fonts. Сам шрифт с ClipSD не распространяется.
  • Сервисы перевода MyMemory и Google Cloud Translation: используются через интернет, только когда вы переводите текст. Подробно: политика конфиденциальности.
