ClipSD 1.32.2: a free screenshot tool with an editor for Windows 10/11 (x64) and Linux (x86-64). License GPL-3.0-or-later.
Alt+W selects an area; arrows, numbers, blur and text marks; copy text from an image (OCR); translate text on screen.
Site: https://clipsd.github.io/   Source: https://github.com/clipsd/clipsd   Checksums of the release files: https://clipsd.github.io/downloads/SHA256SUMS

LINUX (x86-64 only, glibc 2.35 or newer; installs for the current user, no sudo)
Fits: Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora 36+, openSUSE Tumbleweed, Arch and derivatives, Zorin OS 17+, Pop!_OS 22.04+, elementary OS 7+.
Does not fit: ARM (Raspberry Pi), Ubuntu 20.04 and older, Debian 11, CentOS 7. One build serves all of them.
One command:
  curl -fsSL https://clipsd.github.io/install.sh | bash
(It reads the version from https://clipsd.github.io/channel/stable/latest.json, downloads the archive from GitHub Releases, checks SHA-256 against https://clipsd.github.io/downloads/SHA256SUMS and stops on a mismatch, then runs the install.sh of the archive. Extra arguments: ... | bash -s -- --force-replace-dev)
By hand, with the check:
  curl -fLO https://github.com/clipsd/clipsd/releases/download/v1.32.2/ClipSD-1.32.2-linux-x86_64.tar.gz
  curl -fLO https://clipsd.github.io/downloads/SHA256SUMS
  sha256sum -c --ignore-missing SHA256SUMS
  tar -xzf ClipSD-1.32.2-linux-x86_64.tar.gz
  cd clipsd-1.32.2 && bash install.sh
Installed into ~/.local/share/clipsd, the command is ~/.local/bin/clipsd (also in the application menu).
Alt+W: GNOME and X11 sessions set it themselves; in KDE and other Wayland desktops assign the command `clipsd --region` in the keyboard settings.
Uninstall: bash ~/.local/share/clipsd/current/uninstall.sh   (add --purge to delete settings and screenshots too)

WINDOWS 10/11 x64 (current user, no administrator rights)
Installer: https://github.com/clipsd/clipsd/releases/download/v1.32.2/ClipSD-1.32.2-Setup.exe   SHA-256 d963e260a9f7ed653e932ec44e67a6cdeb59c1ff0aa3f441fc38f75b8184158c
Check (PowerShell): (Get-FileHash .\ClipSD-1.32.2-Setup.exe).Hash
Silent install: .\ClipSD-1.32.2-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
A silent install goes into %LOCALAPPDATA%\Programs\ClipSD and does not start the program: start it from the Start menu (ClipSD) or run %LOCALAPPDATA%\Programs\ClipSD\ClipSD.exe. The installer has no signing certificate yet, so SmartScreen may show a blue window: More info, Run anyway.
Uninstall: Settings > Apps > ClipSD, or "%LOCALAPPDATA%\Programs\ClipSD\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART (settings and screenshots stay unless you delete them).

Updates: the program checks once a day and offers to update itself. Screenshots never leave the computer; only text sent for translation goes online. More facts for assistants: https://clipsd.github.io/llms-full.txt
