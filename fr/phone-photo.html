Capture/photo depuis le téléphone : mode d’emploi

Une capture d’écran ou une photo du téléphone s’ouvre aussitôt dans l’éditeur ClipSD de l’ordinateur. Rien à installer sur le téléphone, pas d’Internet : tout passe par votre Wi-Fi domestique.

  1. Sur l’ordinateur. Cliquez sur l’icône ClipSD près de l’horloge et choisissez « Capture/photo depuis le téléphone ». Une fenêtre avec un QR code s’ouvre. Si le pare-feu est actif, cliquez une fois sur « Autoriser » (Ubuntu) ou confirmez la fenêtre Windows.
  2. Sur le téléphone. Visez le QR code avec l’appareil photo et ouvrez le lien. Le téléphone et l’ordinateur doivent être sur le même réseau Wi-Fi. Touchez « Prendre une photo » (après la prise de vue, touchez « OK » dans l’appareil photo) ou « Choisir une capture ou une photo ».
  3. Envoyez. Touchez « Envoyer et terminer » ou « Envoyer et en prendre une autre » : la photo s’ouvre aussitôt dans l’éditeur de l’ordinateur. Après chaque photo, la réception reste ouverte 3 minutes de plus pour prendre la suivante.

Bon à savoir

  • L’ordinateur réduit la photo à la taille de son écran. Pour la taille complète, cochez « Enregistrer les photos en taille réelle » dans la fenêtre.
  • Les métadonnées de l’image (par exemple le lieu de prise de vue) ne sont pas conservées sur l’ordinateur.
  • La photo circule sur le réseau domestique sans chiffrement : utilisez-le chez vous, où le Wi-Fi a un mot de passe, pas dans un café ou un hôtel.
  • Les photos non envoyées restent sur le téléphone jusqu’à une heure : si la connexion s’est fermée, rouvrez « Capture/photo depuis le téléphone » sur l’ordinateur, scannez le nouveau code avec le même téléphone et le même navigateur, et la page propose de les envoyer.

Pas de connexion : que faire

Trouvez dans le tableau ce que vous voyez et faites une ou deux actions à droite.

Windows : « Autoriser à nouveau », le réseau doit être « Privé ». Autre pare-feu ou protection : autorisez les connexions entrantes vers les ports 8765-8767 depuis le réseau domestique.

iPhoneRien à autoriser, Safari et Chrome fonctionnent. Si rien ne s’ouvre, vérifiez le Wi-Fi et le VPN.

« Code déjà ouvert sur un autre téléphone »Un autre téléphone a pris le code. Cliquez sur « Afficher un nouveau code » et scannez-le avec le bon téléphone.
« La fenêtre a reçu toutes les photos »20 photos à la fois. Cliquez sur « Afficher un nouveau code ».
« Photo trop volumineuse »Plus de 25 Mo. Prenez-la en taille normale ou choisissez une autre image.
« Format HEIC »L’ordinateur ne l’ouvre pas. Dans les réglages de l’appareil photo, choisissez le format le plus compatible (JPEG) ou une autre image.
