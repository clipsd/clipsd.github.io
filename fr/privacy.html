Politique de confidentialité de ClipSD

En vigueur à compter du : 2026-11-20.

En bref

  • Les captures d'écran, le presse-papiers, les noms de fichiers et de dossiers ne quittent jamais votre ordinateur.
  • Seul le texte que vous envoyez à traduire part sur Internet, ainsi que l'adresse e-mail pour le service MyMemory si vous en avez indiqué une. Ce texte va directement au service de traduction ; l'auteur de ClipSD ne le reçoit pas.
  • Si vous cliquez vous-même sur « Envoyer » dans la fenêtre « Évaluer ClipSD », l'auteur reçoit les étoiles, le texte de votre avis (si vous en avez écrit un), la langue de l'interface, la version du programme et la plateforme. Ni nom, ni e-mail, ni numéro d'installation, ni captures d'écran.
  • Sans votre commande, le programme ne contacte que la page de mises à jour de ClipSD sur GitHub : une fois par jour, il demande s'il existe une nouvelle version. Cela se désactive dans les paramètres. Pas de compteurs, pas de publicité, pas de profils, pas de vente de données.
  • Si vous écrivez à l'auteur par e-mail, l'auteur conserve votre adresse et votre message.

Qui est responsable

Sergey Dayneko (Сергей Дайнеко), auteur de ClipSD, personne physique en Bulgarie. E-mail : clipsd.app@gmail.com

ClipSD est un logiciel libre et gratuit (GNU GPL v3). Tout ce que le programme envoie sur le réseau se trouve dans trois fichiers source : clipshot/translate.py (traduction), clipshot/updater.py (mises à jour) et clipshot/feedback.py (évaluation du programme).

Ce qui quitte le programme, où cela va et pourquoi

1. Traduction (seulement quand vous cliquez sur un bouton de traduction)

  • Quand : vous cliquez sur « Traduire la sélection » ou « Traduire tout l'écran », sur le bouton de traduction de l'éditeur, ou vous faites passer la fenêtre de traduction dans une autre langue.
  • Ce qui est envoyé : le texte que le programme a reconnu dans la zone choisie.
  • Avec « Traduire tout l'écran », il s'agit de tout le texte du moniteur où se trouve le cadre ou le curseur.
  • Le code de la langue cible est envoyé avec le texte.
  • Si vous avez indiqué une adresse e-mail pour MyMemory, elle est envoyée avec la requête.
  • Le service voit votre adresse IP, comme pour toute requête Internet. L'en-tête de la requête indique le nom du programme, ClipSD.
  • La capture d'écran elle-même n'est pas envoyée.
  • Où : le service choisi dans les paramètres. MyMemory (Translated S.r.l., Italie), par défaut : https://mymemory.translated.net (s'ouvre dans un nouvel onglet)
  • Google Cloud Translation (Google LLC, États-Unis), si vous avez connecté votre propre clé Google Cloud : https://cloud.google.com/translate (s'ouvre dans un nouvel onglet)
  • Service de secours : si un service a épuisé son quota gratuit et que l'autre est connecté, le texte part vers l'autre.
  • Pourquoi : pour vous montrer la traduction.
  • Qui le reçoit : uniquement le service de traduction. La requête part de votre ordinateur directement vers lui ; l'auteur de ClipSD ne la voit ni ne la conserve.
  • Conservation : les services conservent les requêtes selon leurs propres règles : MyMemory https://mymemory.translated.net/doc/privacy.php (s'ouvre dans un nouvel onglet), Google https://policies.google.com/privacy (s'ouvre dans un nouvel onglet) et les conditions de Google Cloud.
  • Comment refuser : ne pas cliquer sur les boutons de traduction. La traduction peut être désactivée dans les paramètres, section « Traduction de l'image ».

2. Vérification de l'adresse e-mail et de la clé (seulement quand vous les saisissez)

  • Quand vous enregistrez une adresse e-mail pour MyMemory, le programme envoie à MyMemory une traduction d'essai du mot « Hello » avec cette adresse, pour vérifier que le service l'accepte.
  • Quand vous saisissez une clé Google Cloud, le programme envoie à Google une traduction d'essai avec cette clé.
  • La clé Google n'est conservée que sur votre ordinateur (voir ci-dessous) et n'est envoyée qu'à Google.

3. Vérification et téléchargement des mises à jour

  • Quand : une fois par jour, la première fois une minute après le lancement, et quand vous cliquez sur « Rechercher des mises à jour » dans le menu de l'icône.
  • Ce qui est envoyé : une requête pour deux fichiers : la description de la dernière version latest.json et sa signature numérique. Quand vous cliquez sur « Mettre à jour », une requête supplémentaire pour télécharger le fichier de la nouvelle version. Le serveur voit l'adresse IP de votre ordinateur, comme pour toute requête sur Internet. L'en-tête de la requête indique le nom et la version du programme, par exemple ClipSD/1.31.0. Le programme n'envoie aucun identifiant d'installation ni aucune information sur votre ordinateur, vos paramètres ou vos captures.
  • Où : la page de mises à jour clipsd.github.io/channel/stable/latest.json et les fichiers de la version sur https://github.com/clipsd/clipsd/releases (s'ouvre dans un nouvel onglet) ; les deux sont hébergés par GitHub (GitHub Inc., États-Unis), règles de GitHub : https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement (s'ouvre dans un nouvel onglet)
  • Pourquoi : vous proposer une nouvelle version et l'installer si vous êtes d'accord.
  • Comment refuser : décochez « Rechercher automatiquement les mises à jour » dans les paramètres, section « Démarrage ». Le programme ne contacte alors la page de mises à jour que quand vous cliquez vous-même sur « Rechercher des mises à jour ».
  • L'installation sous Linux ne télécharge rien elle-même : tout le nécessaire est déjà dans l'archive.

4. Évaluation du programme

  • Quand : seulement quand vous cliquez vous-même sur « Envoyer » dans la fenêtre « Évaluer ClipSD ». La fenêtre se propose d'elle-même une fois, après 7 jours d'utilisation et 20 captures d'écran. « Plus tard » la repousse de 30 jours, elle n'apparaît pas plus de 3 fois, et il y a un bouton « Ne plus afficher ». Vous pouvez aussi ouvrir la fenêtre vous-même : l'élément « Évaluer ClipSD » dans le menu de l'icône près de l'horloge et dans le menu « ? » de l'éditeur. Après l'envoi d'une évaluation, cet élément du menu affiche votre évaluation, et une seconde ne peut pas être envoyée. Vous pouvez la modifier ou la faire supprimer par e-mail (voir « Comment la modifier ou la faire supprimer »).
  • Ce qui est envoyé : les étoiles de 1 à 5 ; le texte de l'avis, si vous en avez écrit un (jusqu'à 1000 caractères) ; la langue de l'interface ; la version du programme ; la plateforme (Windows ou Linux) ; un numéro aléatoire de cette évaluation, pour qu'un second envoi ne soit pas enregistré deux fois ; la durée pendant laquelle la fenêtre d'évaluation est restée ouverte (protection contre l'envoi automatique).
  • Ni nom, ni e-mail, ni numéro d'installation, ni informations sur votre ordinateur, ni captures d'écran. Les adresses e-mail dans le texte de l'avis sont remplacées par « <e-mail> » avant l'enregistrement.
  • Adresse IP : le récepteur (Cloudflare) voit l'adresse IP de votre ordinateur, comme pour toute requête Internet. Pour limiter le nombre d'évaluations (« pas plus de 5 par jour depuis une même adresse »), ce n'est pas l'adresse elle-même qui est conservée, mais son empreinte irréversible calculée avec une clé secrète. L'enregistrement est supprimé le lendemain (UTC). Le récepteur ne tient pas de journaux de requêtes.
  • Où : le récepteur d'évaluations de l'auteur sur Cloudflare Workers (Cloudflare, Inc., États-Unis), base de données Cloudflare D1, stockage dans l'UE. Règles de Cloudflare : https://www.cloudflare.com/privacypolicy/ (s'ouvre dans un nouvel onglet)
  • Publication : le texte d'un avis n'apparaît sur ce site qu'après vérification par l'auteur, avec les étoiles, la langue, la version du programme et la date (le jour, sans l'heure). Les étoiles sans texte comptent tout de suite dans la note moyenne et dans le nombre d'évaluations.
  • Sans Internet : l'évaluation attend dans le dossier des paramètres (le dossier rating-outbox à côté de config.json). La première tentative a lieu tout de suite quand vous cliquez sur « Envoyer ». S'il n'y a pas de connexion, ClipSD réessaie lui-même au plus tôt une heure après, puis au plus tôt un jour après la deuxième tentative (vérification une fois par heure tant que le programme tourne, et au démarrage). Pas plus de 3 tentatives au total, puis l'évaluation est supprimée.
  • Base légale : le consentement, vous avez cliqué vous-même sur « Envoyer » (art. 6, par. 1, point a du RGPD).
  • Durée : tant que ClipSD collecte des évaluations ou jusqu'à votre demande de suppression.
  • Comment la modifier ou la faire supprimer : écrivez à clipsd.app@gmail.com la date et le texte de l'évaluation (pour une évaluation sans texte : la date, les étoiles et la version). Il n'y a pas de numéro d'installation, donc une évaluation ne se retrouve que par ces informations. Suppression et réponse dans un délai d'un mois.

Messages à l'auteur

  • Ce que reçoit l'auteur : si vous écrivez à clipsd.app@gmail.com, l'auteur reçoit votre adresse e-mail, votre nom si votre messagerie l'indique, le texte et tout ce que vous joignez (par exemple une capture d'écran).
  • Où c'est conservé : dans le service de messagerie Gmail (Google), selon les règles de Google : https://policies.google.com/privacy (s'ouvre dans un nouvel onglet)
  • Pourquoi : pour répondre à une question ou traiter un bug ou une idée.
  • Base juridique : intérêt légitime à répondre à votre message (art. 6, par. 1, point f, du RGPD).
  • Durée : la correspondance est supprimée 12 mois après le dernier message concernant votre question.
  • Comment la faire supprimer plus tôt : écrivez depuis la même adresse à clipsd.app@gmail.com ; la correspondance est supprimée et vous recevez une réponse dans un délai d'un mois.
  • N'envoyez pas de mots de passe, de numéros de carte ni d'autres données personnelles inutiles. Si elles sont visibles sur une capture d'écran, couvrez-les avec un rectangle plein.

Le site web

Le site web est servi par GitHub Pages (GitHub, Inc., États-Unis). GitHub enregistre les adresses IP des visiteurs dans ses journaux de sécurité et les conserve selon ses propres règles : https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement (s'ouvre dans un nouvel onglet) . L'auteur de ClipSD n'a pas accès à ces journaux. Quel que soit votre choix dans la bannière, GitHub Pages reçoit votre adresse IP et les données techniques de la requête HTTP (adresse de la page, type de navigateur, heure) : cela sert à fournir le site et n'est pas de l'analyse.

Compteurs de visites du site (seulement avec votre consentement)

Ces compteurs appartiennent au site web. Le programme ClipSD n'a rien à voir avec eux et n'envoie rien sans votre commande (voir plus haut). Tant que vous n'avez pas cliqué sur « Accepter » dans la bannière, aucun script de compteur n'est chargé et aucun cookie n'est déposé. Fermer la bannière sans choisir vaut refus : rien n'est chargé. Votre choix (la réponse, la version de la politique et la date) est conservé dans votre navigateur (localStorage, clé clipsd-consent) pendant 12 mois ou jusqu'à un changement de la politique, puis la bannière redemande. Vous pouvez modifier ce choix à tout moment avec le lien « Paramètres des cookies » en bas de chaque page.

  • Google Analytics 4 (fournisseur Google LLC ; les données sont traitées dans l'EEE et aux États-Unis). Collecte : pages consultées, temps passé sur la page, région approximative, type de navigateur et d'appareil, langue, site d'origine ; un identifiant aléatoire de visiteur dans les cookies _ga et _ga_<numéro> (ces deux seulement). L'adresse IP est transmise à Google dans le cadre de la connexion réseau et peut être traitée brièvement, notamment pour déterminer la position approximative ; Google déclare que Google Analytics 4 n'enregistre ni ne conserve les adresses IP des utilisateurs de l'EEE. Les signaux Google, la personnalisation des annonces et le partage de données avec les produits Google sont désactivés. Durée des cookies : jusqu'à 2 ans. Durée de conservation des événements sur les serveurs de Google : 2 mois (l'auteur la règle dans le compte Google Analytics) ; les rapports agrégés peuvent être conservés plus longtemps. Transfert hors de l'UE : Google peut traiter des données dans l'EEE et aux États-Unis ; pour les transferts couverts, Google LLC utilise le cadre de protection des données UE-États-Unis ; dans les autres cas, Google prévoit des clauses contractuelles types. Règles de Google : https://policies.google.com/privacy (s'ouvre dans un nouvel onglet)
  • Base juridique : votre consentement (art. 6, par. 1, point a du RGPD et règles ePrivacy sur les cookies), donné séparément pour chaque compteur. Destinataires : les fournisseurs des compteurs nommés ci-dessus ; l'auteur voit des statistiques de visites pseudonymisées (identifiant aléatoire, pages, région, appareil). Pourquoi : savoir quelles pages sont lues et comment améliorer le site. Aucune décision automatisée ni profilage vous concernant n'est mis en œuvre.
  • Vos droits : accès, rectification, effacement, limitation, portabilité, opposition et droit de retirer votre consentement. L'auteur est responsable des compteurs et traite lui-même ces demandes : écrivez à clipsd.app@gmail.com en indiquant la valeur de votre cookie _ga (ou l'identifiant Yandex) afin de retrouver votre visite. L'auteur ne vous renvoie pas à Google ou à Yandex à sa place. Vous pouvez aussi saisir la Commission de protection des données personnelles de Bulgarie (https://www.cpdp.bg (s'ouvre dans un nouvel onglet)) ou l'autorité de votre pays. Un refus n'a aucune conséquence négative : le site et le programme fonctionnent de la même façon.
  • Si vous n'avez pas écrit à l'auteur et n'avez pas accepté l'analyse, l'auteur ne dispose normalement d'aucune donnée permettant d'isoler votre visite. Après votre accord, l'auteur accède à des statistiques pseudonymisées sur la visite.
  • Retirer son consentement : en bas de n'importe quelle page, cliquez sur « Paramètres des cookies » puis « Refuser ». Le retrait arrête tout nouveau chargement des compteurs. Le site supprime les cookies et identifiants locaux qu'il peut atteindre et recharge la page ; les données sur les domaines des fournisseurs eux-mêmes ne peuvent être supprimées que par les outils du navigateur ou par le fournisseur. Le retrait ne supprime pas les données traitées légalement auparavant.

La seule requête vers une autre adresse que le site fait sans votre consentement concerne les évaluations : la page d'accueil demande au récepteur d'évaluations (Cloudflare Workers, Cloudflare, Inc., États-Unis) un résumé, c'est-à-dire la note moyenne, le nombre d'évaluations et les avis approuvés. Le récepteur voit votre adresse IP, comme pour toute requête. Cette requête ne contient ni cookies ni compteurs, et votre choix dans la bannière ne la modifie pas. Règles de Cloudflare : https://www.cloudflare.com/privacypolicy/ (s'ouvre dans un nouvel onglet)

Ce que le programme ne fait pas

ClipSD n'envoie aucune information sur son fonctionnement ou ses plantages et ne collecte aucun identifiant d'installation. Le programme ne se connecte à Internet que pour la traduction (quand vous cliquez sur le bouton), pour les mises à jour (section 3) et avec une évaluation, si vous cliquez vous-même sur « Envoyer » (section 4).

Ce qui reste sur votre ordinateur

  • Les paramètres, y compris l'adresse e-mail pour MyMemory : le fichier config.json dans le dossier ~/.config/clipsd (Windows : %APPDATA%\ClipSD). Les versions 1.29 et plus anciennes le gardaient dans .config/clipshot ; au premier lancement de la 1.30 ou plus récente, il est copié dans le nouveau dossier et l'ancienne copie reste.
  • La clé Google Cloud et le compteur de caractères traduits : dans le même dossier. Sous Linux, le fichier de la clé n'est lisible que par vous.
  • Les compteurs de jours d'utilisation et de captures d'écran pour la fenêtre d'évaluation, et les repères du nombre d'affichages de cette fenêtre : dans config.json. Y figurent aussi les étoiles et le jour de l'évaluation que vous avez envoyée (pour la fenêtre « Vous avez déjà évalué ClipSD »).
  • Une évaluation qui n'a pas pu partir (pas d'Internet) : dans le dossier rating-outbox à côté de config.json, jusqu'à son envoi (section 4).
  • Les fichiers de service des mises à jour (la version téléchargée le temps de l'installation, le marqueur de démarrage, le résultat de la dernière mise à jour) : sous Linux ~/.local/share/clipsd et ~/.local/state/clipsd, sous Windows %LOCALAPPDATA%\ClipSD.
  • Les captures d'écran : un dossier à l'intérieur de Téléchargements (Windows Downloads\Screenshots, Linux « Загрузки/Скриншоты » ou Downloads/Screenshots) ou celui que vous avez choisi dans les paramètres.

Quand vous désinstallez le programme, les paramètres et les captures restent, sauf si vous avez demandé vous-même leur suppression (sous Windows, une case dans le programme de désinstallation, sous Linux, l'option --purge). Les fichiers de service des mises à jour sont supprimés avec le programme.

Vos droits

Vous pouvez demander quelles données vous concernant l'auteur détient, en obtenir une copie, les faire rectifier ou supprimer, en limiter le traitement et vous y opposer. Tant que vous n'avez pas écrit vous-même à l'auteur ni envoyé d'évaluation, il n'a aucune donnée vous concernant : sans votre commande, le programme n'envoie rien à l'auteur. Si vous avez écrit, écrivez depuis la même adresse à clipsd.app@gmail.com ; vous recevez une réponse dans un délai d'un mois. Si vous avez envoyé une évaluation, indiquez la date et le texte de l'évaluation (section 4) : l'auteur n'a ni adresse e-mail ni numéro d'installation pour elle, une évaluation ne peut donc pas être retrouvée autrement. Pour les données détenues par les services de traduction, adressez-vous à MyMemory et à Google via les liens ci-dessus.

Vous pouvez aussi déposer une plainte auprès d'une autorité de contrôle : en Bulgarie, la Commission de protection des données personnelles (Комисия за защита на личните данни, https://www.cpdp.bg (s'ouvre dans un nouvel onglet)), ou l'autorité de votre pays.

Enfants

ClipSD n'est pas spécialement conçu pour les enfants. Si vous avez moins de 16 ans, indiquez une adresse e-mail pour la traduction et écrivez à l'auteur uniquement avec l'autorisation de vos parents.

Modifications

Une nouvelle version de cette politique est publiée sur cette page avec une nouvelle date. Si le programme commence à envoyer autre chose, la politique change dans la même version.
