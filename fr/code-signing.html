ClipSD : signature et vérification des fichiers

Les fichiers sont-ils signés ?

Pas encore. Le programme d'installation pour Windows n'est pas signé avec un certificat numérique : un certificat payant coûte de l'argent chaque année, et la signature gratuite pour les projets libres n'a pas encore été mise en place. C'est pourquoi Windows affiche la fenêtre bleue SmartScreen au premier lancement. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

Le programme installe lui-même les mises à jour, mais seulement celles qui sont signées. La description de la nouvelle version (latest.json) est signée avec la clé de l'auteur (Ed25519) ; la partie publique de la clé est intégrée au programme. Le programme rejette une description sans signature valide, dont la date de validité a expiré ou dont la version est plus ancienne qu'une version déjà vue, et vérifie le fichier téléchargé d'après la taille et la somme SHA-256 de la description signée. L'auteur conserve la clé privée séparément de GitHub : même quelqu'un qui remplacerait les fichiers sur GitHub ne pourrait pas les faire passer pour une mise à jour.

Comment vérifier qu'un fichier est authentique

À côté de chaque bouton de téléchargement du site se trouve une somme de contrôle SHA-256 : une empreinte de 64 caractères du fichier. Si le fichier change ne serait-ce que d'un octet, l'empreinte est différente. La liste des sommes se trouve à côté des fichiers de la version sur GitHub et sur le site : downloads/SHA256SUMS.

Windows, PowerShell :

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, terminal :

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Comparez le résultat avec la somme indiquée sur le site. Si le résultat correspond à la somme, le fichier est bien celui que l'auteur a publié. Sinon, ne le lancez pas et écrivez à l'auteur.

Où récupérer les fichiers

Uniquement dans la section de téléchargement du site web de ClipSD ou sur la page de la version sur GitHub : https://github.com/clipsd/clipsd/releases (s'ouvre dans un nouvel onglet) . Les boutons du site mènent au même endroit. Les portails de téléchargement peuvent reconditionner le programme d'installation en y ajoutant leurs propres éléments.

Code source

ClipSD est distribué sous licence GNU GPL v3. Le code source de chaque version se trouve sur GitHub : https://github.com/clipsd/clipsd (s'ouvre dans un nouvel onglet) , la page de la version v<version> contient les archives du code source. Vous pouvez compiler le programme vous-même et comparer.

Signaler un fichier suspect

Si vous trouvez un fichier nommé ClipSD dont la somme de contrôle ne correspond pas à celle du site, ou qui se comporte de façon suspecte, écrivez à clipsd.app@gmail.com.

Politique de signature de code (Code signing policy)

La section suivante est la politique de signature de code de ClipSD. Elle est en anglais, car SignPath Foundation la vérifie sous cette forme.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation was submitted on 20 November 2026. Until it is approved, the installer from this website is not signed. The Microsoft Store version is signed by Microsoft.

What is signed: the installer ClipSD-<version>-Setup.exe, the launcher ClipSD.exe, the program ClipSD-app.exe and the uninstaller unins000.exe. Only files that GitHub Actions built from the sources of the repository https://github.com/clipsd/clipsd (s'ouvre dans un nouvel onglet) are signed. Libraries of other projects (Python, Qt and others) are included as their authors ship them; they are not signed with our certificate.

Team roles:

  • Committers and reviewers: Sergey Dayneko, members of the clipsd organization: https://github.com/orgs/clipsd/people (s'ouvre dans un nouvel onglet)
  • Approvers (every signing request): Sergey Dayneko, owner of the clipsd organization: https://github.com/orgs/clipsd/people?query=role%3Aowner (s'ouvre dans un nouvel onglet)

All members sign in to GitHub and SignPath with two-factor authentication. Every release is signed only after manual approval.

Privacy: ClipSD privacy policy. On its own the program sends data in three cases only:

  • the update page: once a day, can be switched off in the settings;
  • the translation service: when you press a translate button;
  • the ClipSD ratings receiver: only when you press "Send" in the rating window yourself.

Publisher shown by Windows: "SignPath Foundation", not the author's name. The certificate is issued to the foundation; the signature confirms that the file was built automatically from the open source code of this repository.

How to check the signature: right-click the file, Properties, tab Digital Signatures: the list must show "SignPath Foundation". Or in PowerShell:

Get-AuthenticodeSignature .\ClipSD-<version>-Setup.exe | Format-List Status, SignerCertificate

Status must be Valid.
