ClipSD: firma y comprobación de los archivos

¿Están firmados los archivos?

Todavía no. El instalador para Windows no está firmado con un certificado digital: un certificado de pago cuesta dinero cada año, y la firma gratuita para proyectos de código abierto aún no se ha tramitado. Por eso Windows muestra la ventana azul de SmartScreen en la primera ejecución. Pulse «Más información» y después «Ejecutar de todas formas».

El programa instala las actualizaciones por sí mismo, pero solo las firmadas. La descripción de la versión nueva (latest.json) está firmada con la clave del autor (Ed25519); la parte pública de la clave va integrada en el programa. El programa rechaza una descripción sin firma válida, caducada o con una versión más antigua que otra ya vista, y comprueba el tamaño y la suma SHA-256 del archivo descargado según la descripción firmada. La clave privada la guarda el autor aparte de GitHub, así que ni siquiera quien sustituya los archivos en GitHub podrá hacerlos pasar por una actualización.

Cómo comprobar que un archivo es auténtico

Junto a cada botón de descarga del sitio web hay una suma de comprobación SHA-256: una huella de 64 caracteres del archivo. Si el archivo cambia aunque sea en un solo byte, la huella es distinta. La lista de sumas está junto a los archivos de la versión en GitHub y en el sitio web: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, terminal:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Compare el resultado con la suma del sitio web. Si coincide, el archivo es el que publicó el autor. Si no, no lo ejecute y escriba al autor.

Dónde conseguir los archivos

Solo en la sección de descargas del sitio web de ClipSD o en la página de la versión en GitHub: https://github.com/clipsd/clipsd/releases (se abre en una pestaña nueva) . Los botones del sitio web llevan al mismo lugar. Los portales de descargas pueden reempaquetar el instalador con añadidos propios.

Código fuente

ClipSD se distribuye bajo la GNU GPL v3. El código fuente de cada versión está en GitHub: https://github.com/clipsd/clipsd (se abre en una pestaña nueva) , la página de la versión v<version> tiene los archivos de código fuente. Puede compilar el programa usted mismo y comparar el resultado.

Avisar de un archivo sospechoso

Si encuentra un archivo llamado ClipSD cuya suma de comprobación no coincide con la del sitio web, o que se comporta de forma sospechosa, escriba a clipsd.app@gmail.com.

Política de firma de código (Code signing policy)

La sección siguiente es la política de firma de código de ClipSD. Está en inglés porque SignPath Foundation la revisa en esa forma.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation was submitted on 20 November 2026. Until it is approved, the installer from this website is not signed. The Microsoft Store version is signed by Microsoft.

What is signed: the installer ClipSD-<version>-Setup.exe, the launcher ClipSD.exe, the program ClipSD-app.exe and the uninstaller unins000.exe. Only files that GitHub Actions built from the sources of the repository https://github.com/clipsd/clipsd (se abre en una pestaña nueva) are signed. Libraries of other projects (Python, Qt and others) are included as their authors ship them; they are not signed with our certificate.

Team roles:

  • Committers and reviewers: Sergey Dayneko, members of the clipsd organization: https://github.com/orgs/clipsd/people (se abre en una pestaña nueva)
  • Approvers (every signing request): Sergey Dayneko, owner of the clipsd organization: https://github.com/orgs/clipsd/people?query=role%3Aowner (se abre en una pestaña nueva)

All members sign in to GitHub and SignPath with two-factor authentication. Every release is signed only after manual approval.

Privacy: ClipSD privacy policy. On its own the program sends data in three cases only:

  • the update page: once a day, can be switched off in the settings;
  • the translation service: when you press a translate button;
  • the ClipSD ratings receiver: only when you press "Send" in the rating window yourself.

Publisher shown by Windows: "SignPath Foundation", not the author's name. The certificate is issued to the foundation; the signature confirms that the file was built automatically from the open source code of this repository.

How to check the signature: right-click the file, Properties, tab Digital Signatures: the list must show "SignPath Foundation". Or in PowerShell:

Get-AuthenticodeSignature .\ClipSD-<version>-Setup.exe | Format-List Status, SignerCertificate

Status must be Valid.
