ClipSD: Signatur und Prüfung der Dateien

Sind die Dateien signiert?

Noch nicht. Das Windows-Installationsprogramm ist nicht mit einem digitalen Zertifikat signiert: Ein kostenpflichtiges Zertifikat kostet jedes Jahr Geld, und eine kostenlose Signatur für Open-Source-Projekte ist noch nicht eingerichtet. Deshalb zeigt Windows beim ersten Start das blaue SmartScreen-Fenster. Klicken Sie auf „Weitere Informationen“, dann auf „Trotzdem ausführen“.

Updates installiert das Programm selbst, aber nur signierte. Die Beschreibung der neuen Version (latest.json) ist mit dem Schlüssel des Autors signiert (Ed25519); der öffentliche Teil des Schlüssels ist in das Programm eingebaut. Das Programm lehnt eine Beschreibung ohne gültige Signatur, mit abgelaufenem Gültigkeitsdatum oder mit einer älteren als der bereits bekannten Version ab und prüft die heruntergeladene Datei anhand der Größe und der SHA-256-Summe aus der signierten Beschreibung. Den privaten Schlüssel bewahrt der Autor getrennt von GitHub auf. Deshalb kann selbst jemand, der die Dateien auf GitHub austauscht, sie nicht als Update ausgeben.

So prüfen Sie, ob eine Datei echt ist

Neben jeder Download-Schaltfläche auf der Website steht eine SHA-256-Prüfsumme: ein Fingerabdruck der Datei aus 64 Zeichen. Ändert sich die Datei auch nur um ein Byte, ist der Fingerabdruck ein anderer. Die Liste der Summen liegt neben den Release-Dateien auf GitHub und auf der Website: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, Terminal:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Vergleichen Sie das Ergebnis mit der Summe auf der Website. Stimmt sie überein, entspricht die Datei der vom Autor veröffentlichten Datei. Wenn nicht, führen Sie sie nicht aus und schreiben Sie dem Autor.

Wo Sie die Dateien bekommen

Nur im Download-Bereich der ClipSD-Website oder auf der Release-Seite auf GitHub: https://github.com/clipsd/clipsd/releases (öffnet in neuem Tab) . Die Schaltflächen der Website führen ebenfalls dorthin. Download-Portale können das Installationsprogramm mit eigenen Zusätzen neu verpacken.

Quellcode

ClipSD wird unter der Lizenz GNU GPL v3 verbreitet. Der Quellcode jeder Version liegt auf GitHub: https://github.com/clipsd/clipsd (öffnet in neuem Tab) , auf der Release-Seite für v<version> gibt es die Quellarchive. Sie können das Programm selbst erstellen und vergleichen.

Verdächtige Datei melden

Wenn Sie eine Datei namens ClipSD finden, deren Prüfsumme nicht mit der Website übereinstimmt oder die sich verdächtig verhält, schreiben Sie an clipsd.app@gmail.com.
