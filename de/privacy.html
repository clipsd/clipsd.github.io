ClipSD-Datenschutzerklärung

Gültig ab: 2026-11-19.

Kurz gefasst

  • Screenshots, die Zwischenablage sowie Datei- und Ordnernamen verlassen Ihren Computer nie.
  • Ins Internet geht nur der Text, den Sie selbst zur Übersetzung senden, und die E-Mail-Adresse für den Dienst MyMemory, falls Sie eine angegeben haben. Dieser Text geht direkt an den Übersetzungsdienst; der Autor von ClipSD erhält ihn nicht.
  • Von sich aus greift das Programm nur auf die Update-Seite von ClipSD auf GitHub zu: Einmal am Tag fragt es nach, ob es eine neue Version gibt. Das lässt sich in den Einstellungen ausschalten. Keine Zähler, keine Werbung, keine Profile, kein Verkauf von Daten.
  • Wenn Sie dem Autor per E-Mail schreiben, behält der Autor Ihre Adresse und Ihre Nachricht.

Wer verantwortlich ist

Sergey Dayneko (Сергей Дайнеко), Autor von ClipSD, Privatperson, Bulgarien. E-Mail: clipsd.app@gmail.com

ClipSD ist freie Open-Source-Software (GNU GPL v3). Alles, was das Programm über das Netzwerk sendet, steht in zwei Quellcode-Dateien: clipshot/translate.py (Übersetzung) und clipshot/updater.py (Updates).

Was das Programm verlässt, wohin es geht und wozu

1. Übersetzung (nur wenn Sie eine Schaltfläche zum Übersetzen drücken)

  • Wann: Sie klicken auf „Auswahl übersetzen“, „Ganzen Bildschirm übersetzen“, die Übersetzen-Schaltfläche im Editor oder stellen das Übersetzungsfenster auf eine andere Sprache um.
  • Was gesendet wird: der Text, den das Programm im gewählten Bereich erkannt hat.
  • Bei „Ganzen Bildschirm übersetzen“ ist das der gesamte Text auf dem Monitor, auf dem der Rahmen oder der Mauszeiger steht.
  • Zusammen mit dem Text wird der Code der Zielsprache gesendet.
  • Wenn Sie eine E-Mail-Adresse für MyMemory angegeben haben, wird sie mit der Anfrage gesendet.
  • Der Dienst sieht die IP-Adresse Ihres Computers, wie bei jeder Internetanfrage. Der Header der Anfrage enthält den Namen des Programms ClipSD.
  • Der Screenshot selbst wird nicht gesendet.
  • Wohin: an den in den Einstellungen gewählten Dienst. MyMemory (Translated S.r.l., Italien), der Standarddienst: https://mymemory.translated.net
  • Google Cloud Translation (Google LLC, USA), wenn Sie Ihren eigenen Google-Cloud-Schlüssel verbunden haben: https://cloud.google.com/translate
  • Ausweichdienst: Hat ein Dienst sein kostenloses Kontingent aufgebraucht und der andere ist verbunden, geht der Text an den anderen.
  • Wozu: um Ihnen die Übersetzung zu zeigen.
  • Wer ihn erhält: nur der Übersetzungsdienst. Die Anfrage geht von Ihrem Computer direkt dorthin; der Autor von ClipSD sieht sie weder noch speichert er sie.
  • Speicherung: Die Dienste speichern Anfragen nach ihren eigenen Regeln: MyMemory https://mymemory.translated.net/doc/privacy.php , Google https://policies.google.com/privacy und die Google-Cloud-Bedingungen.
  • So verzichten Sie darauf: Drücken Sie die Übersetzen-Schaltflächen nicht. Die Übersetzung lässt sich in den Einstellungen im Bereich „Übersetzung aus Bild“ ausschalten.

2. Prüfung der E-Mail-Adresse und des Schlüssels (nur wenn Sie sie eingeben)

  • Wenn Sie eine E-Mail-Adresse für MyMemory speichern, sendet das Programm an MyMemory eine Testübersetzung des Wortes „Hello“ mit dieser Adresse, um zu prüfen, ob der Dienst sie akzeptiert.
  • Wenn Sie einen Google-Cloud-Schlüssel eingeben, sendet das Programm an Google eine Testübersetzung mit diesem Schlüssel.
  • Der Google-Schlüssel wird nur auf Ihrem Computer gespeichert (siehe unten) und nur an Google gesendet.

3. Suche nach Updates und Download

  • Wann: einmal am Tag, das erste Mal eine Minute nach dem Start, und wenn Sie im Menü des Symbols auf „Nach Updates suchen“ klicken.
  • Was gesendet wird: eine Anfrage nach zwei Dateien: der Beschreibung der neuesten Version latest.json und ihrer digitalen Signatur. Wenn Sie auf „Aktualisieren“ klicken, wird zusätzlich die Datei der neuen Version angefordert. Der Server sieht die IP-Adresse Ihres Computers, wie bei jeder Internetanfrage. Der Header der Anfrage enthält den Namen und die Version des Programms, zum Beispiel ClipSD/1.31.0. Keine Installationskennung und keine Angaben zu Ihrem Computer, Ihren Einstellungen oder Screenshots werden gesendet.
  • Wohin: an die Update-Seite clipsd.github.io/channel/stable/latest.json und an die Release-Dateien unter https://github.com/clipsd/clipsd/releases ; beide laufen bei GitHub (GitHub Inc., USA), Regeln von GitHub: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
  • Wozu: um Ihnen eine neue Version anzubieten und sie zu installieren, wenn Sie zustimmen.
  • So verzichten Sie darauf: Entfernen Sie in den Einstellungen im Bereich „Start“ den Haken bei „Automatisch nach Updates suchen“. Dann greift das Programm nur auf die Update-Seite zu, wenn Sie selbst auf „Nach Updates suchen“ klicken.
  • Die Installation unter Linux lädt selbst nichts herunter: Alles Nötige ist schon im Archiv.

Nachrichten an den Autor

  • Was der Autor erhält: Wenn Sie an clipsd.app@gmail.com schreiben, erhält der Autor Ihre E-Mail-Adresse, Ihren Namen, falls Ihr Mailprogramm ihn anzeigt, den Text und alles, was Sie anhängen (zum Beispiel einen Screenshot).
  • Wo es gespeichert wird: im E-Mail-Dienst Gmail (Google), nach den Regeln von Google: https://policies.google.com/privacy
  • Wozu: um eine Frage zu beantworten oder einen Fehler oder eine Idee zu klären.
  • Rechtsgrundlage: berechtigtes Interesse, Ihre Nachricht zu beantworten (Art. 6 Abs. 1 Buchst. f DSGVO).
  • Wie lange: Die Korrespondenz wird 12 Monate nach der letzten Nachricht zu Ihrer Frage gelöscht.
  • So lassen Sie sie früher löschen: Schreiben Sie von derselben Adresse an clipsd.app@gmail.com; die Korrespondenz wird gelöscht, und Sie erhalten innerhalb eines Monats eine Antwort.
  • Senden Sie keine Passwörter, Kartennummern oder andere unnötige personenbezogene Daten. Sind sie auf einem Screenshot sichtbar, decken Sie sie mit einem ausgefüllten Rechteck ab.

Was das Programm nicht tut

ClipSD sendet keine Informationen über den Betrieb oder Abstürze des Programms und erfasst keine Installationskennung. Ins Internet geht das Programm nur für die Übersetzung (wenn Sie die Schaltfläche drücken) und für Updates (Abschnitt 3).

Was auf Ihrem Computer bleibt

  • Einstellungen, einschließlich der E-Mail-Adresse für MyMemory: die Datei config.json im Ordner ~/.config/clipsd (Windows: %APPDATA%\ClipSD). Die Versionen 1.29 und älter speicherten sie in .config/clipshot; beim ersten Start von 1.30 oder neuer wird sie in den neuen Ordner kopiert, die alte Kopie bleibt.
  • Der Google-Cloud-Schlüssel und der Zähler der übersetzten Zeichen: im selben Ordner. Unter Linux ist die Schlüsseldatei nur für Sie lesbar.
  • Hilfsdateien der Updates (die heruntergeladene Version während der Installation, der Startmarker, das Ergebnis des letzten Updates): unter Linux ~/.local/share/clipsd und ~/.local/state/clipsd, unter Windows %LOCALAPPDATA%\ClipSD.
  • Screenshots: ein Ordner innerhalb von „Downloads“ (Windows Downloads\Screenshots, Linux Downloads/Screenshots) oder der Ordner, den Sie in den Einstellungen gewählt haben.

Beim Deinstallieren des Programms bleiben Einstellungen und Screenshots erhalten, außer Sie haben selbst verlangt, sie zu löschen (unter Windows mit dem Haken im Deinstallationsprogramm, unter Linux mit der Option --purge). Die Hilfsdateien der Updates werden zusammen mit dem Programm entfernt.
