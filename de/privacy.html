ClipSD-Datenschutzerklärung

Gültig ab: 2026-11-20.

Kurz gefasst

  • Screenshots, die Zwischenablage sowie Datei- und Ordnernamen verlassen Ihren Computer nie.
  • Ins Internet geht nur der Text, den Sie selbst zur Übersetzung senden, und die E-Mail-Adresse für den Dienst MyMemory, falls Sie eine angegeben haben. Dieser Text geht direkt an den Übersetzungsdienst; der Autor von ClipSD erhält ihn nicht.
  • Wenn Sie im Fenster „ClipSD bewerten“ selbst auf „Senden“ drücken, erhält der Autor die Sterne, den Text Ihrer Rezension (falls Sie einen geschrieben haben), die Sprache der Oberfläche, die Programmversion und die Plattform. Kein Name, keine E-Mail-Adresse, keine Installationsnummer, keine Screenshots.
  • Ohne Ihren Befehl greift das Programm nur auf die Update-Seite von ClipSD auf GitHub zu: Einmal am Tag fragt es nach, ob es eine neue Version gibt. Das lässt sich in den Einstellungen ausschalten. Keine Zähler, keine Werbung, keine Profile, kein Verkauf von Daten.
  • Wenn Sie dem Autor per E-Mail schreiben, behält der Autor Ihre Adresse und Ihre Nachricht.

Wer verantwortlich ist

Sergey Dayneko (Сергей Дайнеко), Autor von ClipSD, Privatperson, Bulgarien. E-Mail: clipsd.app@gmail.com

ClipSD ist freie Open-Source-Software (GNU GPL v3). Alles, was das Programm über das Netzwerk sendet, steht in drei Quellcode-Dateien: clipshot/translate.py (Übersetzung), clipshot/updater.py (Updates) und clipshot/feedback.py (Bewertung des Programms).

Was das Programm verlässt, wohin es geht und wozu

1. Übersetzung (nur wenn Sie eine Schaltfläche zum Übersetzen drücken)

  • Wann: Sie klicken auf „Auswahl übersetzen“, „Ganzen Bildschirm übersetzen“, die Übersetzen-Schaltfläche im Editor oder stellen das Übersetzungsfenster auf eine andere Sprache um.
  • Was gesendet wird: der Text, den das Programm im gewählten Bereich erkannt hat.
  • Bei „Ganzen Bildschirm übersetzen“ ist das der gesamte Text auf dem Monitor, auf dem der Rahmen oder der Mauszeiger steht.
  • Zusammen mit dem Text wird der Code der Zielsprache gesendet.
  • Wenn Sie eine E-Mail-Adresse für MyMemory angegeben haben, wird sie mit der Anfrage gesendet.
  • Der Dienst sieht die IP-Adresse Ihres Computers, wie bei jeder Internetanfrage. Der Header der Anfrage enthält den Namen des Programms ClipSD.
  • Der Screenshot selbst wird nicht gesendet.
  • Wohin: an den in den Einstellungen gewählten Dienst. MyMemory (Translated S.r.l., Italien), der Standarddienst: https://mymemory.translated.net (öffnet in neuem Tab)
  • Google Cloud Translation (Google LLC, USA), wenn Sie Ihren eigenen Google-Cloud-Schlüssel verbunden haben: https://cloud.google.com/translate (öffnet in neuem Tab)
  • Ausweichdienst: Hat ein Dienst sein kostenloses Kontingent aufgebraucht und der andere ist verbunden, geht der Text an den anderen.
  • Wozu: um Ihnen die Übersetzung zu zeigen.
  • Wer ihn erhält: nur der Übersetzungsdienst. Die Anfrage geht von Ihrem Computer direkt dorthin; der Autor von ClipSD sieht sie weder noch speichert er sie.
  • Speicherung: Die Dienste speichern Anfragen nach ihren eigenen Regeln: MyMemory https://mymemory.translated.net/doc/privacy.php (öffnet in neuem Tab) , Google https://policies.google.com/privacy (öffnet in neuem Tab) und die Google-Cloud-Bedingungen.
  • So verzichten Sie darauf: Drücken Sie die Übersetzen-Schaltflächen nicht. Die Übersetzung lässt sich in den Einstellungen im Bereich „Übersetzung aus Bild“ ausschalten.

2. Prüfung der E-Mail-Adresse und des Schlüssels (nur wenn Sie sie eingeben)

  • Wenn Sie eine E-Mail-Adresse für MyMemory speichern, sendet das Programm an MyMemory eine Testübersetzung des Wortes „Hello“ mit dieser Adresse, um zu prüfen, ob der Dienst sie akzeptiert.
  • Wenn Sie einen Google-Cloud-Schlüssel eingeben, sendet das Programm an Google eine Testübersetzung mit diesem Schlüssel.
  • Der Google-Schlüssel wird nur auf Ihrem Computer gespeichert (siehe unten) und nur an Google gesendet.

3. Suche nach Updates und Download

  • Wann: einmal am Tag, das erste Mal eine Minute nach dem Start, und wenn Sie im Menü des Symbols auf „Nach Updates suchen“ klicken.
  • Was gesendet wird: eine Anfrage nach zwei Dateien: der Beschreibung der neuesten Version latest.json und ihrer digitalen Signatur. Wenn Sie auf „Aktualisieren“ klicken, wird zusätzlich die Datei der neuen Version angefordert. Der Server sieht die IP-Adresse Ihres Computers, wie bei jeder Internetanfrage. Der Header der Anfrage enthält den Namen und die Version des Programms, zum Beispiel ClipSD/1.31.0. Keine Installationskennung und keine Angaben zu Ihrem Computer, Ihren Einstellungen oder Screenshots werden gesendet.
  • Wohin: an die Update-Seite clipsd.github.io/channel/stable/latest.json und an die Release-Dateien unter https://github.com/clipsd/clipsd/releases (öffnet in neuem Tab) ; beide laufen bei GitHub (GitHub Inc., USA), Regeln von GitHub: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement (öffnet in neuem Tab)
  • Wozu: um Ihnen eine neue Version anzubieten und sie zu installieren, wenn Sie zustimmen.
  • So verzichten Sie darauf: Entfernen Sie in den Einstellungen im Bereich „Start“ den Haken bei „Automatisch nach Updates suchen“. Dann greift das Programm nur auf die Update-Seite zu, wenn Sie selbst auf „Nach Updates suchen“ klicken.
  • Die Installation unter Linux lädt selbst nichts herunter: Alles Nötige ist schon im Archiv.

4. Bewertung des Programms

  • Wann: nur wenn Sie im Fenster „ClipSD bewerten“ selbst auf „Senden“ drücken. Das Fenster erscheint von selbst einmal, nach 7 Tagen Nutzung und 20 Screenshots. „Später“ verschiebt es um 30 Tage, es wird höchstens 3-mal gezeigt, und es gibt die Schaltfläche „Nicht mehr anzeigen“. Sie können das Fenster auch selbst öffnen: der Eintrag „ClipSD bewerten“ im Symbolmenü an der Uhr und im Menü „?“ des Editors. Nach einer gesendeten Bewertung zeigt dieser Menüeintrag Ihre Bewertung, eine zweite lässt sich nicht senden. Sie können die Bewertung per E-Mail ändern oder löschen lassen (siehe „So ändern oder löschen Sie sie“).
  • Was gesendet wird: Sterne von 1 bis 5; der Text der Rezension, falls Sie einen geschrieben haben (bis zu 1000 Zeichen); die Sprache der Oberfläche; die Programmversion; die Plattform (Windows oder Linux); eine zufällige Nummer dieser Bewertung, damit ein erneutes Senden sie nicht doppelt speichert; wie lange das Bewertungsfenster geöffnet war (Schutz vor automatischem Senden).
  • Kein Name, keine E-Mail-Adresse, keine Installationsnummer, keine Angaben zu Ihrem Computer und keine Screenshots. E-Mail-Adressen im Text der Rezension werden vor dem Speichern durch „<e-mail>“ ersetzt.
  • IP-Adresse: Der Empfänger (Cloudflare) sieht die IP-Adresse Ihres Computers, wie bei jeder Internetanfrage. Um die Zahl der Bewertungen zu begrenzen („höchstens 5 pro Tag von einer Adresse“), wird nicht die Adresse selbst gespeichert, sondern ein nicht umkehrbarer Hash mit einem geheimen Schlüssel. Der Eintrag wird am nächsten Tag (UTC) gelöscht. Der Empfänger führt keine Anfrageprotokolle.
  • Wohin: der Bewertungsempfänger des Autors auf Cloudflare Workers (Cloudflare, Inc., USA), Datenbank Cloudflare D1, Speicherung in der EU. Regeln von Cloudflare: https://www.cloudflare.com/privacypolicy/ (öffnet in neuem Tab)
  • Veröffentlichung: Der Text einer Rezension erscheint auf dieser Website erst nach Prüfung durch den Autor, zusammen mit den Sternen, der Sprache, der Programmversion und dem Datum (der Tag, ohne Uhrzeit). Sterne ohne Text zählen sofort in der Durchschnittsbewertung und in der Zahl der Bewertungen.
  • Ohne Internet: Die Bewertung wartet im Einstellungsordner (der Ordner rating-outbox neben config.json). Der erste Versuch erfolgt sofort, wenn Sie „Senden“ drücken. Ohne Verbindung versucht ClipSD es selbst erneut, frühestens nach einer Stunde, nach dem zweiten Versuch frühestens nach einem Tag (Prüfung einmal pro Stunde, solange das Programm läuft, und beim Start). Höchstens 3 Versuche insgesamt, danach wird die Bewertung gelöscht.
  • Rechtsgrundlage: Einwilligung, Sie haben selbst auf „Senden“ gedrückt (Art. 6 Abs. 1 Buchst. a DSGVO).
  • Dauer: solange ClipSD Bewertungen sammelt oder bis zu Ihrer Bitte um Löschung.
  • So ändern oder löschen Sie sie: Schreiben Sie an clipsd.app@gmail.com das Datum und den Text der Bewertung (bei einer Bewertung ohne Text: das Datum, die Sterne und die Version). Es gibt keine Installationsnummer, daher wird eine Bewertung nur anhand dieser Angaben gefunden. Löschung und Antwort innerhalb eines Monats.

Was das Programm nicht tut

ClipSD sendet keine Informationen über den Betrieb oder Abstürze des Programms und erfasst keine Installationskennung. Ins Internet geht das Programm nur für die Übersetzung (wenn Sie die Schaltfläche drücken), für Updates (Abschnitt 3) und mit einer Bewertung, wenn Sie selbst auf „Senden“ drücken (Abschnitt 4).

Was auf Ihrem Computer bleibt

  • Einstellungen, einschließlich der E-Mail-Adresse für MyMemory: die Datei config.json im Ordner ~/.config/clipsd (Windows: %APPDATA%\ClipSD). Die Versionen 1.29 und älter speicherten sie in .config/clipshot; beim ersten Start von 1.30 oder neuer wird sie in den neuen Ordner kopiert, die alte Kopie bleibt.
  • Der Google-Cloud-Schlüssel und der Zähler der übersetzten Zeichen: im selben Ordner. Unter Linux ist die Schlüsseldatei nur für Sie lesbar.
  • Die Zähler der Nutzungstage und der Screenshots für das Bewertungsfenster und die Vermerke, wie oft dieses Fenster gezeigt wurde: in config.json. Dort stehen auch die Sterne und der Tag Ihrer gesendeten Bewertung (für das Fenster „Sie haben ClipSD bereits bewertet“).
  • Eine Bewertung, die noch nicht gesendet werden konnte (kein Internet): im Ordner rating-outbox neben config.json, bis sie gesendet wird (Abschnitt 4).
  • Hilfsdateien der Updates (die heruntergeladene Version während der Installation, der Startmarker, das Ergebnis des letzten Updates): unter Linux ~/.local/share/clipsd und ~/.local/state/clipsd, unter Windows %LOCALAPPDATA%\ClipSD.
  • Screenshots: ein Ordner innerhalb von „Downloads“ (Windows Downloads\Screenshots, Linux Downloads/Screenshots) oder der Ordner, den Sie in den Einstellungen gewählt haben.

Beim Deinstallieren des Programms bleiben Einstellungen und Screenshots erhalten, außer Sie haben selbst verlangt, sie zu löschen (unter Windows mit dem Haken im Deinstallationsprogramm, unter Linux mit der Option --purge). Die Hilfsdateien der Updates werden zusammen mit dem Programm entfernt.

Ihre Rechte

Sie können Auskunft darüber verlangen, welche Daten der Autor über Sie hat, eine Kopie erhalten, Daten berichtigen oder löschen lassen, die Verarbeitung einschränken und widersprechen. Solange Sie dem Autor nicht selbst geschrieben und keine Bewertung gesendet haben, hat er keine Daten über Sie: Ohne Ihren Befehl sendet das Programm dem Autor nichts. Wenn Sie geschrieben haben, schreiben Sie von derselben Adresse an clipsd.app@gmail.com; Sie erhalten innerhalb eines Monats eine Antwort. Wenn Sie eine Bewertung gesendet haben, nennen Sie das Datum und den Text der Bewertung (Abschnitt 4): Der Autor hat dazu weder eine E-Mail-Adresse noch eine Installationsnummer, eine Bewertung lässt sich daher nicht anders finden. Für Daten bei den Übersetzungsdiensten wenden Sie sich über die obigen Links an MyMemory und Google.

Sie können sich außerdem bei einer Aufsichtsbehörde beschweren: in Bulgarien bei der Kommission für den Schutz personenbezogener Daten (Комисия за защита на личните данни, https://www.cpdp.bg (öffnet in neuem Tab)) oder bei der Behörde Ihres Landes.

Kinder

ClipSD ist nicht für Kinder gemacht. Wenn Sie unter 16 Jahre alt sind, geben Sie eine E-Mail-Adresse für die Übersetzung an und schreiben Sie dem Autor nur mit Erlaubnis Ihrer Eltern.
