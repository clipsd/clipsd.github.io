Screenshot/Foto vom Smartphone: so geht es

Ein Screenshot oder Foto vom Smartphone öffnet sich sofort im ClipSD-Editor auf dem Computer. Auf dem Smartphone muss nichts installiert werden, Internet ist nicht nötig: Alles läuft über Ihr WLAN zu Hause.

  1. Am Computer. Klicken Sie auf das ClipSD-Symbol neben der Uhr und wählen Sie „Screenshot/Foto vom Smartphone“. Es öffnet sich ein Fenster mit QR-Code. Ist am Computer eine Firewall aktiv, klicken Sie einmal auf „Erlauben“ (Ubuntu) oder bestätigen Sie das Windows-Fenster.
  2. Am Smartphone. Richten Sie die Kamera auf den QR-Code und öffnen Sie den Link. Smartphone und Computer müssen im selben WLAN sein. Tippen Sie auf „Fotografieren“ (nach der Aufnahme in der Kamera „OK“) oder „Screenshot oder Foto auswählen“.
  3. Senden. Tippen Sie auf „Senden und beenden“ oder „Senden und weiter aufnehmen“: Das Foto öffnet sich sofort im Editor am Computer. Nach jedem Foto bleibt der Empfang noch 3 Minuten offen, damit Sie das nächste aufnehmen können.

Gut zu wissen

  • Der Computer verkleinert das Foto selbst auf die Größe seines Bildschirms. Für die volle Größe setzen Sie im Fenster den Haken bei „Fotos in voller Größe speichern“.
  • Die Metadaten des Bildes (zum Beispiel der Aufnahmeort) werden am Computer nicht gespeichert.
  • Das Foto geht ohne Verschlüsselung durch das Heimnetz, nutzen Sie es also zu Hause mit WLAN-Passwort, nicht im Café oder Hotel.
  • Nicht gesendete Fotos bleiben bis zu einer Stunde auf dem Smartphone: Ist die Verbindung beendet, öffnen Sie am Computer erneut „Screenshot/Foto vom Smartphone“, scannen Sie den neuen Code mit demselben Smartphone und Browser, und die Seite bietet das Senden an.

Keine Verbindung: was tun

Suchen Sie in der Tabelle, was Sie sehen, und führen Sie die ein bis zwei Schritte rechts aus.

Was Sie sehenWas tun
Die Seite öffnet nicht, der Browser zeigt ERR_TOO_MANY_RETRIES oder ERR_LOCAL_NETWORK_PERMISSION_MISSING (Smartphone mit Android 17)Einstellungen → Apps → Ihr Browser → Berechtigungen → „Geräte in der Nähe“ → Zulassen, dann den Code erneut scannen. Chrome 158 und neuer fragt selbst „Mit Geräten in der Nähe verbinden?“: „Weiter“ tippen und aktivieren. Chrome und Edge 157 fragen nicht.
Die Seite lädt sehr lange oder „Website nicht erreichbar“Schalten Sie VPN oder einen Blocker (zum Beispiel AdGuard) am Smartphone für eine Minute aus oder erlauben Sie darin den „Zugriff auf das lokale Netzwerk“.
Dasselbe bei eingeschaltetem WLANPrüfen Sie das Netzwerk am Smartphone: Der Name muss derselbe sein wie am Computer. Gastnetz und mobiles Internet gehen nicht: Ist das Smartphone auf mobile Daten gewechselt, schalten Sie diese für eine Minute aus.
Es öffnet in keinem Netz, und der Computer läuft mit Ubuntu oder WindowsUbuntu: im Fenster „Keine Verbindung?“ wählen, dann „Erlauben“ und das Passwort eingeben. Windows: „Erneut erlauben“, das Netz muss „Privat“ sein. Andere Firewall oder anderer Schutz: eingehende Verbindungen zu den Ports 8765-8767 aus dem Heimnetz erlauben.
Am Computer selbst ist ein VPN anEs stört meist nicht. Hilft nichts, schalten Sie es für eine Minute aus.
iPhoneNichts zu erlauben, Safari und Chrome funktionieren. Öffnet es nicht, WLAN und VPN prüfen.
Am Smartphone „Empfang geschlossen“ oder „Empfangszeit abgelaufen“Der Code ist abgelaufen (3 Minuten ohne Smartphone, 3 Minuten nach dem letzten Foto). Am Computer „Neuen Code zeigen“ wählen und den Code scannen.
„Code schon an einem anderen Smartphone geöffnet“Ein anderes Smartphone hat den Code belegt. „Neuen Code zeigen“ wählen und mit dem richtigen Smartphone scannen.
„Das Fenster hat alle Fotos angenommen“20 Fotos auf einmal. „Neuen Code zeigen“ wählen.
„Foto zu groß“Über 25 MB. In normaler Größe aufnehmen oder ein anderes Bild wählen.
„HEIC-Format“Der Computer öffnet es nicht. In den Kameraeinstellungen das kompatibelste Format (JPEG) wählen oder ein anderes Bild nehmen.
„Der Computer konnte Foto N nicht öffnen“Das Foto erneut aufnehmen.
„Die Verbindung zum Computer ist beendet“, Foto nicht gesendetDas Foto bleibt bis zu einer Stunde auf dem Smartphone. Am Computer „Screenshot/Foto vom Smartphone“ öffnen, den neuen Code mit demselben Smartphone und Browser scannen und „Senden“ tippen.
Nichts davon hat geholfenSchließen Sie das Fenster, öffnen Sie „Screenshot/Foto vom Smartphone“ erneut und scannen Sie einen neuen Code. Prüfen Sie, ob Smartphone und Computer im selben Netz sind.
