ClipSD: підпис і перевірка файлів

Чи підписано файли

Поки ні. Інсталятор для Windows не підписано цифровим сертифікатом: платний підпис коштує грошей щороку, а безкоштовний для відкритих проєктів ще не оформлено. Тому під час першого запуску Windows показує синє вікно SmartScreen. Натисніть «Детальніше», потім «Виконати в будь-якому разі».

Оновлення програма ставить сама, але лише підписані. Опис нової версії (latest.json) підписано ключем автора (Ed25519); відкрита частина ключа вшита в програму. Програма відкидає опис без правильного підпису, з простроченим терміном дії або з версією, старішою за ту, яку програма вже бачила, а завантажений файл перевіряє за розміром і сумою SHA-256 з підписаного опису. Закритий ключ зберігається в автора окремо від GitHub, тому навіть той, хто підмінить файли на GitHub, не зможе видати їх за оновлення.

Як перевірити, що файл справжній

Поруч із кожною кнопкою завантаження на сайті є контрольна сума SHA-256: відбиток файла з 64 символів. Якщо файл змінився хоч на один байт, відбиток буде іншим. Список сум лежить поруч із файлами випуску на GitHub і на сайті: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, термінал:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Порівняйте результат із сумою на сайті. Якщо збігається, файл той самий, що опублікував автор. Якщо ні, не запускайте його й напишіть авторові.

Де брати файли

Лише в розділі завантаження на сайті ClipSD або на сторінці випуску на GitHub: https://github.com/clipsd/clipsd/releases (відкриється в новій вкладці) . Кнопки сайту ведуть туди ж. Сайти-каталоги програм можуть перепакувати інсталятор зі своїми доповненнями.

Вихідний код

ClipSD поширюється за ліцензією GNU GPL v3. Вихідний код кожної версії лежить на GitHub: https://github.com/clipsd/clipsd (відкриється в новій вкладці) , на сторінці випуску v<version> є архіви вихідного коду. Ви можете самі зібрати програму й порівняти.

Повідомте про підозрілий файл

Якщо ви знайшли файл із назвою ClipSD, контрольна сума якого не збігається з сайтом або який поводиться підозріло, напишіть на clipsd.app@gmail.com.

Політика підпису коду (Code signing policy)

Наступний розділ є політикою підпису коду ClipSD. Він англійською, бо SignPath Foundation перевіряє його саме в такому вигляді.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation was submitted on 20 November 2026. Until it is approved, the installer from this website is not signed. The Microsoft Store version is signed by Microsoft.

What is signed: the installer ClipSD-<version>-Setup.exe, the launcher ClipSD.exe, the program ClipSD-app.exe and the uninstaller unins000.exe. Only files that GitHub Actions built from the sources of the repository https://github.com/clipsd/clipsd (відкриється в новій вкладці) are signed. Libraries of other projects (Python, Qt and others) are included as their authors ship them; they are not signed with our certificate.

Team roles:

  • Committers and reviewers: Sergey Dayneko, members of the clipsd organization: https://github.com/orgs/clipsd/people (відкриється в новій вкладці)
  • Approvers (every signing request): Sergey Dayneko, owner of the clipsd organization: https://github.com/orgs/clipsd/people?query=role%3Aowner (відкриється в новій вкладці)

All members sign in to GitHub and SignPath with two-factor authentication. Every release is signed only after manual approval.

Privacy: ClipSD privacy policy. On its own the program sends data in three cases only:

  • the update page: once a day, can be switched off in the settings;
  • the translation service: when you press a translate button;
  • the ClipSD ratings receiver: only when you press "Send" in the rating window yourself.

Publisher shown by Windows: "SignPath Foundation", not the author's name. The certificate is issued to the foundation; the signature confirms that the file was built automatically from the open source code of this repository.

How to check the signature: right-click the file, Properties, tab Digital Signatures: the list must show "SignPath Foundation". Or in PowerShell:

Get-AuthenticodeSignature .\ClipSD-<version>-Setup.exe | Format-List Status, SignerCertificate

Status must be Valid.
