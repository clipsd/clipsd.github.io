ClipSD: підпис і перевірка файлів

Чи підписано файли

Поки ні. Інсталятор для Windows не підписано цифровим сертифікатом: платний підпис коштує грошей щороку, а безкоштовний для відкритих проєктів ще не оформлено. Тому під час першого запуску Windows показує синє вікно SmartScreen. Натисніть «Детальніше», потім «Виконати в будь-якому разі».

Оновлення програма ставить сама, але лише підписані. Опис нової версії (latest.json) підписано ключем автора (Ed25519); відкрита частина ключа вшита в програму. Програма відкидає опис без правильного підпису, з простроченим терміном дії або з версією, старішою за ту, яку програма вже бачила, а завантажений файл перевіряє за розміром і сумою SHA-256 з підписаного опису. Закритий ключ зберігається в автора окремо від GitHub, тому навіть той, хто підмінить файли на GitHub, не зможе видати їх за оновлення.

Як перевірити, що файл справжній

Поруч із кожною кнопкою завантаження на сайті є контрольна сума SHA-256: відбиток файла з 64 символів. Якщо файл змінився хоч на один байт, відбиток буде іншим. Список сум лежить поруч із файлами випуску на GitHub і на сайті: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, термінал:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Порівняйте результат із сумою на сайті. Якщо збігається, файл той самий, що опублікував автор. Якщо ні, не запускайте його й напишіть авторові.

Де брати файли

Лише в розділі завантаження на сайті ClipSD або на сторінці випуску на GitHub: https://github.com/clipsd/clipsd/releases . Кнопки сайту ведуть туди ж. Сайти-каталоги програм можуть перепакувати інсталятор зі своїми доповненнями.

Вихідний код

ClipSD поширюється за ліцензією GNU GPL v3. Вихідний код кожної версії лежить на GitHub: https://github.com/clipsd/clipsd , на сторінці випуску v<version> є архіви вихідного коду. Ви можете самі зібрати програму й порівняти.

Повідомте про підозрілий файл

Якщо ви знайшли файл із назвою ClipSD, контрольна сума якого не збігається з сайтом або який поводиться підозріло, напишіть на clipsd.app@gmail.com.
