ClipSD: firma e verifica dei file

I file sono firmati?

Non ancora. Il programma di installazione per Windows non è firmato con un certificato digitale: un certificato a pagamento ha un costo annuale, e la firma gratuita per i progetti open source non è ancora stata predisposta. Per questo al primo avvio Windows mostra la finestra blu di SmartScreen. Fai clic su «Ulteriori informazioni», poi su «Esegui comunque».

Il programma installa gli aggiornamenti da solo, ma solo quelli firmati. La descrizione della nuova versione (latest.json) è firmata con la chiave dell'autore (Ed25519); la parte pubblica della chiave è integrata nel programma. Il programma rifiuta una descrizione senza firma valida, scaduta o con una versione più vecchia di una già vista, e verifica il file scaricato in base alla dimensione e al checksum SHA-256 della descrizione firmata. La chiave privata è conservata dall'autore separatamente da GitHub, quindi anche chi sostituisse i file su GitHub non potrebbe farli passare per un aggiornamento.

Come verificare che un file sia autentico

Accanto a ogni pulsante di download sul sito c'è un checksum SHA-256: un'impronta del file di 64 caratteri. Se il file cambia anche di un solo byte, l'impronta è diversa. L'elenco dei checksum si trova accanto ai file della versione su GitHub e sul sito: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, terminale:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Confronta il risultato con il checksum sul sito. Se coincide, il file è quello pubblicato dall'autore. Se non coincide, non avviarlo e scrivi all'autore.

Dove prendere i file

Solo dalla sezione di download del sito web di ClipSD o dalla pagina della versione su GitHub: https://github.com/clipsd/clipsd/releases . I pulsanti del sito portano allo stesso posto. I portali di download possono riconfezionare il programma di installazione con aggiunte proprie.

Codice sorgente

ClipSD è distribuito con licenza GNU GPL v3. Il codice sorgente di ogni versione è su GitHub: https://github.com/clipsd/clipsd , nella pagina della versione v<version> ci sono gli archivi dei sorgenti. Puoi compilare il programma da solo e confrontarlo con il file pubblicato.

Segnalare un file sospetto

Se trovi un file chiamato ClipSD il cui checksum non coincide con quello del sito, oppure che si comporta in modo sospetto, scrivi a clipsd.app@gmail.com.
