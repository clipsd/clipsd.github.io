ClipSD: assinatura e verificação dos arquivos

Os arquivos são assinados?

Ainda não. O instalador para Windows não é assinado com um certificado digital: um certificado pago custa dinheiro todo ano, e a assinatura gratuita para projetos de código aberto ainda não foi providenciada. Por isso o Windows mostra a janela azul do SmartScreen na primeira execução. Clique em “Mais informações” e depois em “Executar assim mesmo”.

O programa instala as atualizações sozinho, mas só as assinadas. A descrição da nova versão (latest.json) é assinada com a chave do autor (Ed25519); a parte pública da chave vem embutida no programa. O programa rejeita uma descrição sem assinatura válida, com prazo vencido ou com uma versão mais antiga do que uma já vista, e confere o arquivo baixado pelo tamanho e pela soma SHA-256 da descrição assinada. A chave privada fica com o autor, separada do GitHub; por isso, mesmo quem trocar os arquivos no GitHub não consegue fazê-los passar por uma atualização.

Como verificar se um arquivo é autêntico

Ao lado de cada botão de download no site há uma soma de verificação SHA-256: uma impressão digital de 64 caracteres do arquivo. Se o arquivo mudar em um único byte que seja, a impressão digital é diferente. A lista das somas está junto dos arquivos da versão no GitHub e no site: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, terminal:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Compare o resultado com a soma do site. Se coincidir, o arquivo é o que o autor publicou. Se não, não o execute e escreva ao autor.

Onde obter os arquivos

Só na seção de downloads do site do ClipSD ou na página da versão no GitHub: https://github.com/clipsd/clipsd/releases . Os botões do site levam para o mesmo lugar. Portais de download podem reempacotar o instalador com adições próprias.

Código-fonte

O ClipSD é distribuído sob a GNU GPL v3. O código-fonte de cada versão fica no GitHub: https://github.com/clipsd/clipsd , e a página da versão v<version> tem os arquivos de código-fonte. Você mesmo pode compilar o programa e comparar o resultado.

Avisar sobre um arquivo suspeito

Se você encontrar um arquivo chamado ClipSD cuja soma de verificação não coincide com a do site, ou que se comporta de forma suspeita, escreva para clipsd.app@gmail.com.
