ClipSD：签名与文件校验

文件有签名吗？

目前没有。Windows 安装程序没有使用数字证书签名：付费证书每年都要花钱，而面向开源项目的免费签名目前还没有办妥。所以第一次运行时，Windows 会显示蓝色的 SmartScreen 窗口。请点击“更多信息”，再点击“仍要运行”。

程序会自己安装更新，但只安装经过签名的更新。新版本的说明（latest.json）由作者的密钥（Ed25519）签名；公钥内置在程序中。程序会拒绝没有有效签名、已过期或版本比已见过的更旧的说明，并按签名说明中的大小和 SHA-256 校验值检查下载的文件。私钥由作者保管，与 GitHub 分开存放，因此即使有人替换了 GitHub 上的文件，也无法把它们冒充为更新。

如何验证文件是否为作者发布的版本

网站上每个下载按钮旁边都有一个 SHA-256 校验值：这是一个由 64 个字符组成的文件指纹。文件哪怕改动一个字节，指纹也会不同。校验值列表放在 GitHub 上的发布文件旁边，网站上也有：downloads/SHA256SUMS。

Windows，PowerShell：

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux，终端：

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

把结果与网站上的校验值比较。一致，说明文件就是作者发布的那个。不一致，请不要运行，并写信告知作者。

从哪里获取文件

只从 ClipSD 网站的下载区或 GitHub 上的发布页面获取：https://github.com/clipsd/clipsd/releases (在新标签页中打开) 。网站上的按钮也指向那里。软件下载站可能会加入其他内容后重新打包安装程序。

源代码

ClipSD 按 GNU GPL v3 许可证发布。每个版本的源代码都在 GitHub 上：https://github.com/clipsd/clipsd (在新标签页中打开) ，v<version> 发布页面上有源代码压缩包。您可以自己编译程序并进行比对。

报告可疑文件

如果您发现一个名为 ClipSD 的文件，其校验值与网站不符，或行为可疑，请写信到 clipsd.app@gmail.com。

代码签名政策 (Code signing policy)

下面是 ClipSD 的代码签名政策（Code signing policy）。因为 SignPath Foundation 按此形式审核，所以用英文书写。

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation was submitted on 20 November 2026. Until it is approved, the installer from this website is not signed. The Microsoft Store version is signed by Microsoft.

What is signed: the installer ClipSD-<version>-Setup.exe, the launcher ClipSD.exe, the program ClipSD-app.exe and the uninstaller unins000.exe. Only files that GitHub Actions built from the sources of the repository https://github.com/clipsd/clipsd (在新标签页中打开) are signed. Libraries of other projects (Python, Qt and others) are included as their authors ship them; they are not signed with our certificate.

Team roles:

  • Committers and reviewers: Sergey Dayneko, members of the clipsd organization: https://github.com/orgs/clipsd/people (在新标签页中打开)
  • Approvers (every signing request): Sergey Dayneko, owner of the clipsd organization: https://github.com/orgs/clipsd/people?query=role%3Aowner (在新标签页中打开)

All members sign in to GitHub and SignPath with two-factor authentication. Every release is signed only after manual approval.

Privacy: ClipSD privacy policy. On its own the program sends data in three cases only:

  • the update page: once a day, can be switched off in the settings;
  • the translation service: when you press a translate button;
  • the ClipSD ratings receiver: only when you press "Send" in the rating window yourself.

Publisher shown by Windows: "SignPath Foundation", not the author's name. The certificate is issued to the foundation; the signature confirms that the file was built automatically from the open source code of this repository.

How to check the signature: right-click the file, Properties, tab Digital Signatures: the list must show "SignPath Foundation". Or in PowerShell:

Get-AuthenticodeSignature .\ClipSD-<version>-Setup.exe | Format-List Status, SignerCertificate

Status must be Valid.
