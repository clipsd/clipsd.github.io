ClipSD：签名与文件校验

文件有签名吗？

目前没有。Windows 安装程序没有使用数字证书签名：付费证书每年都要花钱，而面向开源项目的免费签名目前还没有办妥。所以第一次运行时，Windows 会显示蓝色的 SmartScreen 窗口。请点击“更多信息”，再点击“仍要运行”。

程序会自己安装更新，但只安装经过签名的更新。新版本的说明（latest.json）由作者的密钥（Ed25519）签名；公钥内置在程序中。程序会拒绝没有有效签名、已过期或版本比已见过的更旧的说明，并按签名说明中的大小和 SHA-256 校验值检查下载的文件。私钥由作者保管，与 GitHub 分开存放，因此即使有人替换了 GitHub 上的文件，也无法把它们冒充为更新。

如何验证文件是否为作者发布的版本

网站上每个下载按钮旁边都有一个 SHA-256 校验值：这是一个由 64 个字符组成的文件指纹。文件哪怕改动一个字节，指纹也会不同。校验值列表放在 GitHub 上的发布文件旁边，网站上也有：downloads/SHA256SUMS。

Windows，PowerShell：

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux，终端：

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

把结果与网站上的校验值比较。一致，说明文件就是作者发布的那个。不一致，请不要运行，并写信告知作者。

从哪里获取文件

只从 ClipSD 网站的下载区或 GitHub 上的发布页面获取：https://github.com/clipsd/clipsd/releases (在新标签页中打开) 。网站上的按钮也指向那里。软件下载站可能会加入其他内容后重新打包安装程序。

源代码

ClipSD 按 GNU GPL v3 许可证发布。每个版本的源代码都在 GitHub 上：https://github.com/clipsd/clipsd (在新标签页中打开) ，v<version> 发布页面上有源代码压缩包。您可以自己编译程序并进行比对。

报告可疑文件

如果您发现一个名为 ClipSD 的文件，其校验值与网站不符，或行为可疑，请写信到 clipsd.app@gmail.com。

代码签名政策 (Code signing policy)

本节说明代码签名目前的状况，以及有了签名之后将如何运作。

状态：ClipSD 向 SignPath Foundation 申请免费代码签名，已于 2026 年 11 月 20 日提交，并于 2026 年 11 月 21 日被拒绝，原因是项目目前知名度还不高。本网站提供的安装程序没有签名，因此 Windows 可能会显示 SmartScreen 窗口。Microsoft Store 版本由 Microsoft 签名。我们之后会再次申请，不早于被拒后三个月。

有了签名之后将如何运作（这是计划，不是当前状态，不承诺时间）：将被签名的有安装程序、启动器、主程序和卸载程序，并且仅限 GitHub Actions 从仓库 https://github.com/clipsd/clipsd (在新标签页中打开) 的源代码构建出的文件。其他项目的库（Python、Qt 等）保持其作者发布时的样子。每次签名只有在 clipsd 组织所有者手动批准后才会进行，相关账户都启用了两步验证。

隐私：ClipSD 隐私政策。程序只在三种情况下自行发送数据：

  • 更新页面：每天一次，可在设置中关闭；
  • 翻译服务：当您按下翻译按钮时；
  • ClipSD 评分接收端：仅当您自己在评分窗口中点击“发送”时。
