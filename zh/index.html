截图

怎么截取屏幕的一部分？

在任意程序中按 Alt+W，用鼠标框选一个区域。按 Enter 在编辑器中打开，按 Ctrl+C 复制并关闭窗口。单击时钟旁的 ClipSD 图标也能做到。

怎么截取整个屏幕？

按 Alt+W 后，不框选直接单击，或按“全屏”（Ctrl+A）。如果有多个显示器，可以一次选择全部，也可以只选其中一个。

怎么遮住银行卡号或人脸？

银行卡号、密码和其他重要数据，请用实心矩形盖住：选择“矩形”（按键 R），按住 Ctrl 绘制。人脸和地址可以用“模糊”（按键 B）遮住：该处会变成方块，一眼看不清，但方块下较大的文字有时仍能辨认出来。

截图保存在哪里？

每张截图会立即保存到“下载”文件夹内的一个文件夹里；编辑后文件会更新。在 Windows 上是 Downloads\Screenshots。在 Linux 上是 Downloads/Screenshots；如果您的主文件夹里有俄语名称的 «Загрузки» 文件夹，则是 «Загрузки/Скриншоты»。文件夹和格式可以在设置中更改。Ctrl+S 保存到文件并关闭编辑器；默认会询问保存位置，这个询问可以在设置中关闭。Enter 把截图复制到剪贴板。

ClipSD 和 Windows 的截图工具有什么不同？

ClipSD 在 Windows 和 Linux 上都能用，而截图工具只有 Windows 才有。编辑器里有带指示线的编号和标注，屏幕上的文字还可以翻译。ClipSD 会记住上次的区域，所以再截同一位置，只需按一次 Enter。

文字与翻译

怎么复制图片中的文字？

按 Alt+W，框选有文字的位置，再按“复制文字”（Ctrl+T）。文字会被高亮：用鼠标划过您需要的部分，它们就已经在剪贴板里了。在编辑器中，“复制文字”按钮或按键 I 也能做到。

怎么翻译屏幕上的文字？

按 Alt+W，框选文字，再按“翻译所选内容”（Ctrl+L）。“选取并翻译”（Ctrl+P）可以框选另一处。翻译模式栏中的“整个屏幕”按钮（Ctrl+Shift+L）会立即翻译边框或光标所在的显示器。编辑器里有一个拆分按钮：“全部翻译”（Shift+Y）翻译整张截图，“所选内容”（Y）翻译您选中的部分。

免费可以翻译多少？

无需注册，立即可用每天 5,000 个字符。填写电子邮箱后，每天 50,000 个字符。使用您自己的 Google Cloud 密钥，每月 500,000 个字符；Google 会要求为密钥绑定银行卡。如果两个服务都已连接，其中一个用完后，ClipSD 会自动切换到另一个。

隐私与网络

ClipSD 会向互联网发送什么？

只发送您提交翻译的文字，以及（如果您填写了的话）给 MyMemory 的电子邮箱。截图、剪贴板和文件名绝不会离开您的电脑。程序自行联网只有一件事：每天在 GitHub 上检查一次是否有新版本；这可以在设置的“启动”部分关闭。

需要联网吗？

截图、编辑、保存和图片取字都不需要联网。翻译和更新需要联网。

快捷键与 Linux

ClipSD 能在使用 Wayland 的 Linux 上运行吗？

可以，X11 和 Wayland 会话都支持。在 GNOME 中，ClipSD 会安装自己的扩展，使 Alt+W 在两种键盘布局下都能使用。在 Wayland 上的其他桌面环境中，请在键盘设置中把一个快捷键指定给命令 clipsd --region。

Alt+W 没有反应怎么办？

请确认时钟旁有 ClipSD 图标：程序必须在运行。在使用 GNOME 的 Linux 上，安装后请注销再重新登录；在此之前 Alt+W 只能在拉丁字母键盘布局下使用。在 Wayland 上的其他桌面环境中，请在键盘设置中把一个快捷键指定给命令 clipsd --region。如果 Alt+W 被其他程序占用，请在 ClipSD 设置的“快捷键”部分选择您自己的快捷键。您也可以单击时钟旁的图标来截取区域。

可以把 Alt+W 改成别的快捷键吗？

可以。在设置的“快捷键”部分，打开 Ctrl、Shift、Alt 或 Win，再选择一个按键。或者点击“录入…”，然后直接按下快捷键。

ClipSD 可以在哪些 Linux 上运行？

任何 64 位（x86-64）、glibc 2.35 或更新的 Linux：Ubuntu 22.04+、Linux Mint 21+、Debian 12+、Fedora 36+、openSUSE Tumbleweed、Arch 及其衍生版、Zorin OS 17+、Pop!_OS 22.04+、elementary OS 7+ 等。 不适用：ARM（树莓派等）、Ubuntu 20.04 及更早、Debian 11、CentOS 7。 所有这些系统共用同一个版本：所需的一切都在压缩包里，不需要为每个版本单独打包。Alt+W：GNOME 和 X11 会话会自动设置；KDE 和其他 Wayland 桌面请在键盘设置中指定。

在 Windows 上安装不需要管理员权限，在 Linux 上不需要管理员密码。
