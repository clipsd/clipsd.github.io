手机截图/拍照：使用方法

手机上的截图或照片会立即在电脑上的 ClipSD 编辑器中打开。手机上无需安装任何东西，也不需要互联网：一切都通过您家里的 Wi-Fi 传输。

  1. 在电脑上。 点击时钟旁的 ClipSD 图标，选择“从手机截图/拍照”。会出现带二维码的窗口。如果电脑开启了防火墙，请点击一次“允许”（Ubuntu），或确认 Windows 的窗口。
  2. 在手机上。 用相机对准二维码并打开链接。手机和电脑必须在同一个 Wi-Fi 网络。点击“拍照”（拍完后在相机中点“确定”）或“选择截图或照片”。
  3. 发送。 点击“发送并结束”或“发送并继续拍”：照片会立即在电脑的编辑器中打开。每张照片之后接收还会保持开放 3 分钟，方便再拍下一张。

值得知道

  • 电脑会自动把照片缩小到屏幕大小。需要完整尺寸时，请在窗口中勾选“以完整尺寸保存照片”。
  • 图片的元数据（例如拍摄地点）不会保存在电脑上。
  • 照片通过家庭网络传输，没有加密，所以请在有 Wi-Fi 密码的家里使用，不要在咖啡馆或酒店使用。
  • 未发送的照片会在手机上保留最多一小时：如果连接已关闭，请在电脑上重新打开“从手机截图/拍照”，用同一部手机和同一个浏览器扫描新的二维码，页面会提示发送。

连接不上：怎么办

在表格中找到您看到的情况，再做右侧的一两个操作。

您看到的情况怎么办
页面打不开，浏览器显示 ERR_TOO_MANY_RETRIES 或 ERR_LOCAL_NETWORK_PERMISSION_MISSING（Android 17 手机）设置 → 应用 → 您的浏览器 → 权限 → “附近设备” → 允许，然后重新扫描二维码。Chrome 158 及更新版本会自己询问“连接到附近设备？”：点击“继续”并开启。Chrome 和 Edge 157 不会询问。
页面加载很久，或显示“无法访问此网站”暂时关闭手机上的 VPN 或拦截程序（例如 AdGuard）一分钟，或在其中允许“访问本地网络”。
开着 Wi-Fi 也是这样检查手机上的网络：名称必须与电脑相同。访客网络和移动数据都不行：如果手机切到了移动数据，请关闭一分钟。
任何网络都打不开，电脑是 Ubuntu 或 WindowsUbuntu：在窗口中点击“无法连接？”，再点击“允许”并输入密码。Windows：“重新允许”，网络必须是“专用”。其他防火墙或安全软件：请允许来自家庭网络、访问端口 8765-8767 的入站连接。
电脑本身开着 VPN通常不会影响。如果都没用，请关闭一分钟。
iPhone无需允许任何内容，Safari 和 Chrome 都可用。如果打不开，请检查 Wi-Fi 和 VPN。
手机上显示“接收已关闭”或“接收时间已结束”二维码已过期（无人连接 3 分钟，或最后一张照片后 3 分钟）。请在电脑上点击“显示新的二维码”并扫描二维码。
“二维码已在另一部手机上打开”二维码被另一部手机占用。请点击“显示新的二维码”，用正确的手机扫描。
“窗口已接收全部照片”一次最多 20 张。请点击“显示新的二维码”。
“照片太大”超过 25 MB。请用普通尺寸拍摄，或选择其他图片。
“HEIC 格式”电脑无法打开。请在相机设置中选择兼容性最好的格式（JPEG），或选择其他图片。
“电脑无法打开第 N 张照片”请重新拍这张照片。
“与电脑的连接已关闭”，照片未发送照片会在手机上保留最多一小时。请在电脑上打开“从手机截图/拍照”，用同一部手机和同一个浏览器扫描新的二维码，然后点击“发送”。
以上都没有帮助关闭窗口，重新打开“从手机截图/拍照”并扫描新的二维码。确认手机和电脑在同一个网络。
