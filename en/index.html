How to take a screenshot: three steps

No account and no uploads. Each screenshot is saved by itself to a folder inside Downloads; Enter in the editor puts it on the clipboard.

  1. 1

    Press Alt+W and select

    The screen freezes. Select the part you need: the magnifier next to the cursor helps you hit the edge exactly. Enter opens the editor.

  2. 2

    Mark what matters

    An arrow, a number, a frame, a label or a marker. Blur hides faces and addresses.

  3. 3

    Paste it into a chat

    Enter copies the screenshot. Paste it into a messenger, an e-mail or a document with the usual Ctrl+V.

Try it on your own computer: Alt+W, then select an area.

Text from images

Text from an image can be copied like ordinary text

A scanned contract, an error window, a video frame, a photo of a sign. Select the place, press "Copy text" or Ctrl+T, and the words in the picture can be selected like in a normal document. This is text recognition (OCR): it runs on your computer, no internet needed.

  • "Range" mode: press on a word and drag, the text is selected in reading order. "Marker" mode: sweep over words, only what you touch is taken.
  • The selection is on the clipboard at once. A window next to it lets you correct the text before pasting.
  • A page in two columns is read column by column, lines do not get mixed.
  • Works offline. On Windows the text is read by the recognition built into Windows: the language of the text must be installed in Windows. On Linux you install the free recognition program Tesseract once: ClipSD shows the ready command.

On-screen translation

Translating text on the screen

Press Alt+W, select the foreign text and press "Translate selection" or Ctrl+L. A whole monitor at once: the "Whole screen" button in the translation mode bar or Ctrl+Shift+L; the monitor with the frame or the cursor is translated. The translation appears in a window right over the text, like a camera translator on a phone.

  • By default the translation is into the program language. You can choose another of the 20 languages with a button on the window itself.
  • "Copy" puts the translation on the clipboard, "Original" shows the source text. Drag the window aside and keep working.
  • In the editor there is a split button: "Translate all" translates the whole screenshot (Shift+Y), "Selection" only the part you select (Y). The translation lies over the screenshot and is not included in the saved image.

Editor features

Tools for every case, each on its own letter key. Work with the mouse or the keyboard.

Tour of the tools: F1 in the editor

  • Arrows and lines

    Straight, double-headed, freehand, smooth. Hold Shift for exact 45° angles.

  • Numbers and callouts

    Circles 1, 2, 3 with a pointer, and speech bubbles with text.

  • Marker and text

    Mark a line in yellow, add a label in any colour.

  • Blur

    Faces and addresses turn into squares. A card number or a password is safer under a filled rectangle: R with Ctrl.

  • Two-step crop

    Drag a frame, adjust the edges, press Enter. Until Enter the screenshot is untouched.

  • Zoom

    Ctrl and the mouse wheel zoom into small details. "Fit" shows the whole screenshot again.

  • Choose a monitor

    Full-screen screenshot: all monitors at once or just one.

  • Move marks

    Hold the right mouse button and drag any mark. No need to switch tools.

  • Same area again

    The next Alt+W highlights the previous frame: no need to select again.

  • Clipboard and file

    Enter in the editor copies the screenshot. Every screenshot is saved as PNG or JPEG by itself.

  • Picture on a screenshot

    Insert a second picture from the clipboard, from a file or as a new screenshot.

  • Light and dark

    Two themes plus your own colours for the frame and panels.

  • Screenshot shape

    Rounded corners, oval or circle. In PNG the area outside the shape is transparent, in JPG it is white.

  • Open windows

    The button at the bottom of the selection panel or the W key: pick a window and the frame fits it exactly.

  • From phone

    A tile on the selection panel and a button in the editor: take a photo with the phone camera and it lands in the screenshot as a separate picture.

  • Your language

    12 interface languages. You choose the language when you first start the program and can change it in the settings or in the menu of the icon next to the clock.

How to uninstall

  • Windows: Settings, section Apps, ClipSD, Uninstall. Or the shortcut "Uninstall ClipSD" in the Start menu. The uninstaller asks whether to delete the ClipSD settings and screenshots too; if you leave the box unticked, the settings in %APPDATA%\ClipSD and the screenshots stay.
  • Linux: in a terminal run bash ~/.local/share/clipsd/current/uninstall.sh. It removes the program, the menu shortcut, autostart, the Alt+W shortcut and the GNOME extension "ClipSD: hotkeys". Settings in ~/.config/clipsd and screenshots stay; to delete them too, run the same file with --purge.

Frequently asked questions

Download and install

Where can I download ClipSD for free, and is it really free?

Yes. You can download ClipSD on this page, in the Download section: an installer for Windows and an archive for Linux. No ads, no trial period, no paid features. The source code is open under the GNU GPL v3 or later: you can read it and check it.

How do I install a new version?

ClipSD installs new versions itself: once a day it checks and offers "Update". To check right away: the icon menu, "Check for updates". If you have version 1.29 or older, download the new version on this page once and install it over the old one. Settings and screenshots are kept.

Why does Windows show a blue window when installing?

ClipSD does not have a paid digital signature yet. Click "More info", then "Run anyway". You can check that the file is genuine with the SHA-256 checksum next to the download button.

Screenshots

How do I take a screenshot of part of the screen?

Press Alt+W in any program and select an area with the mouse. Enter opens it in the editor, Ctrl+C copies it and closes the window. Clicking the ClipSD icon next to the clock does the same.

How do I capture the whole screen?

After Alt+W, click without selecting or press "Full screen" (Ctrl+A). With several monitors, choose all at once or one of them.

How do I hide a card number or a face?

Cover a card number, a password and other important data with a filled rectangle: choose Rectangle (key R) and draw with Ctrl held down. Faces and addresses can be hidden with Blur (key B): the place turns into squares and cannot be read at a glance, but large text under the squares can sometimes be made out.

Where are screenshots saved?

Each screenshot is saved right away to a folder inside Downloads; after edits the file is updated. On Windows it is Downloads\Screenshots. On Linux it is Downloads/Screenshots, or «Загрузки/Скриншоты» if your home folder has a Russian «Загрузки» folder. The folder and format can be changed in the settings. Ctrl+S saves to a file and closes the editor; by default it asks where to save, and the question can be switched off in the settings. Enter copies the screenshot to the clipboard.

How is ClipSD different from the Windows Snipping Tool?

ClipSD works on both Windows and Linux; the Snipping Tool exists only on Windows. The editor has numbers with a pointer and callouts, and text on the screen can be translated. ClipSD remembers the previous area, so the next screenshot of the same place takes one Enter.

Text and translation

How do I copy text from an image?

Press Alt+W, select the place with text and press "Copy text" (Ctrl+T). The words get highlighted: sweep over the ones you need and they are on the clipboard. In the editor the button "Copy text" or the key I does the same.

How do I translate text on the screen?

Press Alt+W, select the text and press "Translate selection" (Ctrl+L). "Select and translate" (Ctrl+P) lets you outline another place. The "Whole screen" button in the translation mode bar (Ctrl+Shift+L) translates the monitor with the frame or the cursor at once. In the editor there is a split button: "Translate all" (Shift+Y) translates the whole screenshot, "Selection" (Y) the part you select.

How much can I translate for free?

5,000 characters a day right away, without registration. With an e-mail, 50,000 characters a day. With your own Google Cloud key, 500,000 characters a month; for the key Google asks for a bank card. If both services are connected and one runs out, ClipSD switches to the other by itself.

Privacy and internet

What does ClipSD send to the internet?

Only the text you send for translation, and the e-mail for MyMemory if you entered one. Screenshots, the clipboard and file names never leave your computer. On its own the program only checks GitHub once a day for a new version; this can be switched off in the settings, section Startup.

Do I need the internet?

You do not need it to take screenshots, use the editor, save or copy text from images. Translation and updates need it.

Hotkeys and Linux

Does ClipSD work on Linux with Wayland?

Yes, in X11 and Wayland sessions. In GNOME, ClipSD installs its own extension so Alt+W works with both keyboard layouts. In other desktops on Wayland, assign a shortcut in the keyboard settings to the command clipsd --region.

What if Alt+W does nothing?

Check that the ClipSD icon is next to the clock: the program must be running. On Linux with GNOME, log out and back in after installing; until then Alt+W works only with the Latin keyboard layout. In other desktops on Wayland, assign a shortcut in the keyboard settings to the command clipsd --region. If another program uses Alt+W, choose your own shortcut in the ClipSD settings, section Keyboard shortcuts. You can also capture an area by clicking the icon next to the clock.

Can I change Alt+W to another shortcut?

Yes. In the settings, section Keyboard shortcuts, switch on Ctrl, Shift, Alt or Win and choose a key. Or press "Record…" and the shortcut itself.

Which Linux does ClipSD run on?

Any 64-bit (x86-64) Linux with glibc 2.35 or newer: Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora 36+, openSUSE Tumbleweed, Arch and its derivatives, Zorin OS 17+, Pop!_OS 22.04+, elementary OS 7+ and similar.
