ClipSD: signing and checking the files

Are the files signed?

Not yet. The Windows installer is not signed with a digital certificate: a paid certificate costs money every year, and free signing for open-source projects has not been arranged yet. That is why Windows shows the blue SmartScreen window on the first run. Click "More info", then "Run anyway".

The program installs updates itself, but only signed ones. The description of the new version (latest.json) is signed with the author's key (Ed25519); the public part of the key is built into the program. The program rejects a description without a valid signature, whose validity period has expired or with a version older than one it has already seen, and checks the downloaded file against the size and SHA-256 sum from the signed description. The private key is kept by the author separately from GitHub, so even someone who swaps the files on GitHub cannot pass them off as an update.

How to check that a file is genuine

Next to every download button on the website there is a SHA-256 checksum: a 64-character fingerprint of the file. If the file changes by even one byte, the fingerprint is different. The list of sums is next to the release files on GitHub and on the website: downloads/SHA256SUMS.

Windows, PowerShell:

Get-FileHash .\ClipSD-<version>-Setup.exe -Algorithm SHA256

Linux, terminal:

sha256sum ClipSD-<version>-linux-x86_64.tar.gz

Compare the result with the sum on the website. If it matches, the file is the one the author published. If not, do not run it and write to the author.

Where to get the files

Only from the download section of the ClipSD website or from the release page on GitHub: https://github.com/clipsd/clipsd/releases (opens in a new tab) . The website buttons lead there too. Download portals may repackage the installer with their own additions.

Source code

ClipSD is licensed under the GNU GPL v3. The source code of every version is on GitHub: https://github.com/clipsd/clipsd (opens in a new tab) , the release page for v<version> has the source archives. You can build the program yourself and compare the result.

Report a suspicious file

If you find a file named ClipSD whose checksum does not match the website, or that behaves suspiciously, write to clipsd.app@gmail.com.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the application to SignPath Foundation was submitted on 20 November 2026. Until it is approved, the installer from this website is not signed. The Microsoft Store version is signed by Microsoft.

What is signed: the installer ClipSD-<version>-Setup.exe, the launcher ClipSD.exe, the program ClipSD-app.exe and the uninstaller unins000.exe. Only files that GitHub Actions built from the sources of the repository https://github.com/clipsd/clipsd (opens in a new tab) are signed. Libraries of other projects (Python, Qt and others) are included as their authors ship them; they are not signed with our certificate.

Team roles:

  • Committers and reviewers: Sergey Dayneko, members of the clipsd organization: https://github.com/orgs/clipsd/people (opens in a new tab)
  • Approvers (every signing request): Sergey Dayneko, owner of the clipsd organization: https://github.com/orgs/clipsd/people?query=role%3Aowner (opens in a new tab)

All members sign in to GitHub and SignPath with two-factor authentication. Every release is signed only after manual approval.

Privacy: ClipSD privacy policy. On its own the program sends data in three cases only:

  • the update page: once a day, can be switched off in the settings;
  • the translation service: when you press a translate button;
  • the ClipSD ratings receiver: only when you press "Send" in the rating window yourself.

Publisher shown by Windows: "SignPath Foundation", not the author's name. The certificate is issued to the foundation; the signature confirms that the file was built automatically from the open source code of this repository.

How to check the signature: right-click the file, Properties, tab Digital Signatures: the list must show "SignPath Foundation". Or in PowerShell:

Get-AuthenticodeSignature .\ClipSD-<version>-Setup.exe | Format-List Status, SignerCertificate

Status must be Valid.
