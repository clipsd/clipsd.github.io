ClipSD privacy policy

Effective from: 2026-11-19.

In short

  • Screenshots, the clipboard, file and folder names never leave your computer.
  • Only text you send for translation goes online, plus the e-mail address for the MyMemory service if you entered one. This text goes straight to the translation service; the author of ClipSD does not receive it.
  • On its own the program contacts only the ClipSD update page on GitHub: once a day it asks whether there is a new version. This can be switched off in the settings. No counters, no ads, no profiles, no selling of data.
  • If you write to the author by e-mail, the author keeps your address and your letter.

Who is responsible

Sergey Dayneko (Сергей Дайнеко), author of ClipSD, a private person, Bulgaria. E-mail: clipsd.app@gmail.com

ClipSD is free, open-source software (GNU GPL v3). Everything the program sends over the network is in two source files: clipshot/translate.py (translation) and clipshot/updater.py (updates).

What leaves the program, where and why

1. Translation (only when you press a translate button)

  • When: you press "Translate selection", "Translate whole screen", the translate button in the editor, or switch the translation window to another language.
  • What is sent: the text the program recognised in the chosen area.
  • With "Translate whole screen" it is all text on the monitor where the frame or the cursor is.
  • The target language code is sent with the text.
  • If you entered an e-mail for MyMemory, it is sent with the request.
  • The service sees your IP address, as with any internet request. The request header names the program ClipSD.
  • The screenshot itself is not sent.
  • Where: the service chosen in the settings. MyMemory (Translated S.r.l., Italy), the default: https://mymemory.translated.net
  • Google Cloud Translation (Google LLC, USA), if you connected your own Google Cloud key: https://cloud.google.com/translate
  • Fallback: if one service has used up its free amount and the other one is connected, the text goes to the other one.
  • Why: to show you the translation.
  • Who receives it: only the translation service. The request goes from your computer straight there; the author of ClipSD neither sees nor keeps it.
  • Storage: the services keep requests under their own rules: MyMemory https://mymemory.translated.net/doc/privacy.php , Google https://policies.google.com/privacy and the Google Cloud terms.
  • How to opt out: do not press the translate buttons. Translation can be switched off in the settings, section "Translation from image".

2. Checking the e-mail and the key (only when you enter them)

  • When you save an e-mail for MyMemory, the program sends MyMemory a test translation of the word "Hello" with that e-mail, to check that the service accepts it.
  • When you enter a Google Cloud key, the program sends Google a test translation with that key.
  • The Google key is stored only on your computer (see below) and is sent only to Google.

3. Checking for and downloading updates

  • When: once a day, the first time a minute after the program starts, and when you press "Check for updates" in the icon menu.
  • What is sent: a request for two files: the description of the latest version latest.json and its digital signature. When you press "Update", the program also requests the file of the new version. The server sees your IP address, as with any internet request. The request header names the program and its version, for example ClipSD/1.31.0. No installation number and nothing about your computer, settings or screenshots is sent.
  • Where: the update page clipsd.github.io/channel/stable/latest.json and the release files at https://github.com/clipsd/clipsd/releases ; both are hosted by GitHub (GitHub, Inc., USA), GitHub's rules: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
  • Why: to offer you a new version and install it when you agree.
  • How to opt out: untick "Check for updates automatically" in the settings, section Startup. Then the program contacts the update page only when you press "Check for updates" yourself.
  • The Linux installation itself downloads nothing: everything it needs is already in the archive.

Letters to the author

  • What the author receives: if you write to clipsd.app@gmail.com, the author gets your e-mail address, your name if your mail shows it, the text and anything you attach (for example a screenshot).
  • Where it is stored: in the Gmail mail service (Google), under Google's rules: https://policies.google.com/privacy
  • Why: to answer a question or sort out a bug or an idea.
  • Legal basis: legitimate interest in answering your letter (Art. 6(1)(f) GDPR).
  • How long: the correspondence is deleted 12 months after the last letter on your question.
  • How to have it deleted earlier: write from the same address to clipsd.app@gmail.com; the correspondence is deleted and you get an answer within a month.
  • Do not send passwords, card numbers or other unneeded personal data. If they are visible on a screenshot, cover them with a filled rectangle.

The website

The website is served by GitHub Pages (GitHub, Inc., USA). GitHub records visitors' IP addresses in its security logs and keeps them under its own rules: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . The author of ClipSD has no access to these logs. Whatever you choose in the banner, GitHub Pages receives your IP address and the technical data of the HTTP request (page address, browser type, time): this is needed to deliver the site and is not analytics.

The website has no visitor counters, ads or cookies and loads nothing from other addresses.

What the program does not do

ClipSD does not send information about how the program runs or crashes and collects no installation identifiers. The program goes online only for translation (when you press the button) and for updates (section 3).

What stays on your computer

  • Settings, including the e-mail for MyMemory: the file config.json in the folder ~/.config/clipsd (Windows: %APPDATA%\ClipSD). Versions 1.29 and older kept it in .config/clipshot; on the first start of 1.30 or newer it is copied to the new folder, the old copy stays.
  • The Google Cloud key and the counter of characters translated: in the same folder. On Linux the key file is readable only by you.
  • Update service files (the downloaded version while it is being installed, the startup marker, the result of the last update): on Linux ~/.local/share/clipsd and ~/.local/state/clipsd, on Windows %LOCALAPPDATA%\ClipSD.
  • Screenshots: a folder inside Downloads (Windows Downloads\Screenshots, Linux Downloads/Screenshots) or the one you chose in the settings.

When you uninstall the program, the settings and screenshots stay unless you asked to delete them (on Windows a tick in the uninstaller, on Linux the --purge option). The update service files are removed together with the program.

Your rights

You may ask what data about you the author has, get a copy, correct, delete, restrict processing and object. Until you write to the author yourself, the author has no data about you: the program sends nothing to the author. If you have written, write from the same address to clipsd.app@gmail.com; you get an answer within a month. For data held by the translation services, ask MyMemory and Google using the links above.

You can also complain to a supervisory authority: in Bulgaria the Commission for Personal Data Protection (https://www.cpdp.bg), or the authority of your country.

Children

ClipSD is not made for children. If you are under 16, enter an e-mail for translation and write to the author only with your parents' permission.

Changes

A new version of this policy is published on this page with a new date. If the program starts sending anything else, the policy changes in the same release.
