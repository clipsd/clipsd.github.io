ClipSD privacy policy

Effective from: 2026-11-20.

In short

  • Screenshots, the clipboard, file and folder names never leave your computer.
  • Only text you send for translation goes online, plus the e-mail address for the MyMemory service if you entered one. This text goes straight to the translation service; the author of ClipSD does not receive it.
  • If you press "Send" yourself in the "Rate ClipSD" window, the author receives the stars, the text of your review (if you wrote one), the interface language, the program version and the platform. No name, e-mail, installation number or screenshots.
  • Without your command the program contacts only the ClipSD update page on GitHub: once a day it asks whether there is a new version. This can be switched off in the settings. No counters, no ads, no profiles, no selling of data.
  • If you write to the author by e-mail, the author keeps your address and your letter.

Who is responsible

Sergey Dayneko (Сергей Дайнеко), author of ClipSD, a private person, Bulgaria. E-mail: clipsd.app@gmail.com

ClipSD is free, open-source software (GNU GPL v3). Everything the program sends over the network is in three source files: clipshot/translate.py (translation), clipshot/updater.py (updates) and clipshot/feedback.py (rating of the program).

What leaves the program, where and why

1. Translation (only when you press a translate button)

  • When: you press "Translate selection", "Translate whole screen", the translate button in the editor, or switch the translation window to another language.
  • What is sent: the text the program recognised in the chosen area.
  • With "Translate whole screen" it is all text on the monitor where the frame or the cursor is.
  • The target language code is sent with the text.
  • If you entered an e-mail for MyMemory, it is sent with the request.
  • The service sees your IP address, as with any internet request. The request header names the program ClipSD.
  • The screenshot itself is not sent.
  • Where: the service chosen in the settings. MyMemory (Translated S.r.l., Italy), the default: https://mymemory.translated.net (opens in a new tab)
  • Google Cloud Translation (Google LLC, USA), if you connected your own Google Cloud key: https://cloud.google.com/translate (opens in a new tab)
  • Fallback: if one service has used up its free amount and the other one is connected, the text goes to the other one.
  • Why: to show you the translation.
  • Who receives it: only the translation service. The request goes from your computer straight there; the author of ClipSD neither sees nor keeps it.
  • Storage: the services keep requests under their own rules: MyMemory https://mymemory.translated.net/doc/privacy.php (opens in a new tab) , Google https://policies.google.com/privacy (opens in a new tab) and the Google Cloud terms.
  • How to opt out: do not press the translate buttons. Translation can be switched off in the settings, section "Translation from image".

2. Checking the e-mail and the key (only when you enter them)

  • When you save an e-mail for MyMemory, the program sends MyMemory a test translation of the word "Hello" with that e-mail, to check that the service accepts it.
  • When you enter a Google Cloud key, the program sends Google a test translation with that key.
  • The Google key is stored only on your computer (see below) and is sent only to Google.

3. Checking for and downloading updates

  • When: once a day, the first time a minute after the program starts, and when you press "Check for updates" in the icon menu.
  • What is sent: a request for two files: the description of the latest version latest.json and its digital signature. When you press "Update", the program also requests the file of the new version. The server sees your IP address, as with any internet request. The request header names the program and its version, for example ClipSD/1.31.0. No installation number and nothing about your computer, settings or screenshots is sent.
  • Where: the update page clipsd.github.io/channel/stable/latest.json and the release files at https://github.com/clipsd/clipsd/releases (opens in a new tab) ; both are hosted by GitHub (GitHub, Inc., USA), GitHub's rules: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement (opens in a new tab)
  • Why: to offer you a new version and install it when you agree.
  • How to opt out: untick "Check for updates automatically" in the settings, section Startup. Then the program contacts the update page only when you press "Check for updates" yourself.
  • The Linux installation itself downloads nothing: everything it needs is already in the archive.

4. Rating the program

  • When: only when you press "Send" yourself in the "Rate ClipSD" window. The window offers itself once, after 7 days of use and 20 screenshots. "Later" postpones it for 30 days, it is shown no more than 3 times, and there is a "Don't show again" button. You can also open the window yourself: the "Rate ClipSD" item in the icon menu by the clock and in the "?" menu of the editor. After a rating has been sent, this menu item shows your rating, and a second one cannot be sent. You can change or delete the rating by e-mail (see "How to change or delete it").
  • What is sent: stars from 1 to 5; the text of the review, if you wrote one (up to 1000 characters); the interface language; the program version; the platform (Windows or Linux); a random number of this rating, so that sending it twice does not record it twice; how long the rating window was open (protection against automatic submission).
  • No name, e-mail, installation number, information about your computer or screenshots. E-mail addresses in the review text are replaced with "<e-mail>" before saving.
  • IP address: the receiver (Cloudflare) sees your IP address, as with any internet request. To limit ratings to 5 per day from one address, it stores not the address but its irreversible hash made with a secret key. The record is deleted the next day (UTC). The receiver keeps no request logs.
  • Where: the author's ratings receiver on Cloudflare Workers (Cloudflare, Inc., USA), the Cloudflare D1 database, stored in the EU. Cloudflare's rules: https://www.cloudflare.com/privacypolicy/ (opens in a new tab)
  • Publication: the text of a review appears on this website only after the author has checked it, together with the stars, the language, the program version and the date (the day, no time). Stars without text count at once in the average rating and in the number of ratings.
  • No internet: the rating waits in the settings folder (the rating-outbox folder next to config.json). The first attempt is made at once when you press "Send". If there is no connection, ClipSD tries again by itself no sooner than an hour later, and after the second attempt no sooner than a day later (it checks once an hour while the program runs, and at startup). No more than 3 attempts in all, then the rating is deleted.
  • Legal basis: consent, you pressed "Send" yourself (Art. 6(1)(a) GDPR).
  • How long: while ClipSD collects ratings, or until you ask for deletion.
  • How to change or delete it: write to clipsd.app@gmail.com with the date and the text of the rating (for a rating without text: the date, the stars and the version). There is no installation number, so a rating can be found only by these details. Deletion and the answer within a month.

Letters to the author

  • What the author receives: if you write to clipsd.app@gmail.com, the author gets your e-mail address, your name if your mail shows it, the text and anything you attach (for example a screenshot).
  • Where it is stored: in the Gmail mail service (Google), under Google's rules: https://policies.google.com/privacy (opens in a new tab)
  • Why: to answer a question or sort out a bug or an idea.
  • Legal basis: legitimate interest in answering your letter (Art. 6(1)(f) GDPR).
  • How long: the correspondence is deleted 12 months after the last letter on your question.
  • How to have it deleted earlier: write from the same address to clipsd.app@gmail.com; the correspondence is deleted and you get an answer within a month.
  • Do not send passwords, card numbers or other unneeded personal data. If they are visible on a screenshot, cover them with a filled rectangle.

The website

The website is served by GitHub Pages (GitHub, Inc., USA). GitHub records visitors' IP addresses in its security logs and keeps them under its own rules: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement (opens in a new tab) . The author of ClipSD has no access to these logs. Whatever you choose in the banner, GitHub Pages receives your IP address and the technical data of the HTTP request (page address, browser type, time): this is needed to deliver the site and is not analytics.

Visitor counters of the website (only with your consent)

These counters belong to the website. The ClipSD program has nothing to do with them and sends nothing without your command (see above). Until you press "Accept" in the banner, no counter script is loaded and no cookie is set. Closing the banner without choosing counts as a refusal: nothing is loaded. Your choice (the answer, the policy version and the date) is kept in your browser (localStorage, key clipsd-consent) for 12 months or until this policy changes; then the banner asks again. You can change the choice at any time with the link "Cookie settings" at the bottom of every page.

  • Google Analytics 4 (provider: Google LLC; the data is processed in the EEA and the USA). Collects: pages viewed, time on the page, approximate region, browser and device type, language, the site you came from; a random visitor identifier in the cookies _ga and _ga_<id> (only these two). The IP address is passed to Google as part of the network connection and may be processed briefly, for example to determine the approximate location; Google states that Google Analytics 4 does not log or store IP addresses of users in the EEA. Google signals, ad personalisation and data sharing with Google products are switched off. Cookie lifetime: up to 2 years. Event data on Google's servers: kept for 2 months (the author sets this in the Google Analytics account); aggregated reports may be kept longer. Transfer outside the EU: Google may process data in the EEA and the USA; for the transfers covered, Google LLC uses the EU-US Data Privacy Framework; in other cases Google provides standard contractual clauses. Google's rules: https://policies.google.com/privacy (opens in a new tab)
  • Legal basis: your consent (Art. 6(1)(a) GDPR and the ePrivacy rules on cookies), given separately for each counter. Recipients: the counter providers named above; the author sees pseudonymous statistics about visits (a random identifier, pages, region, device). Why: to know which pages are read and how the site can be improved. No automated decisions or profiling that affect you are made.
  • Your rights: access, rectification, erasure, restriction, portability and objection, and the right to withdraw consent. The author is responsible for the counters and handles such requests himself: write to clipsd.app@gmail.com and give the value of your _ga cookie (or the Yandex identifier) so that your visit can be found. The author does not send you to Google or Yandex instead. You can also complain to the Commission for Personal Data Protection in Bulgaria (https://www.cpdp.bg (opens in a new tab)) or to the authority in your country. Refusing has no negative consequences: the site and the program work the same.
  • If you have not written to the author and have not agreed to analytics, the author normally has no data that identifies your visit. After you agree, the author gets access to pseudonymous statistics about the visit.
  • Withdrawing consent: press "Cookie settings" at the bottom of any page and "Decline". Withdrawal stops further loading of the counters. The site deletes the first-party cookies and local identifiers it can reach and reloads the page; data on the providers' own domains can be removed only with your browser's tools or by the provider. Withdrawal does not delete data that was lawfully processed earlier.

The only request to another address that the website makes without your consent concerns the ratings: the main page asks the ratings receiver (Cloudflare Workers, Cloudflare, Inc., USA) for a summary, that is the average rating, the number of ratings and the approved reviews. The receiver sees your IP address, as with any request. This request has no cookies and no counters, and your choice in the banner does not affect it. Cloudflare's rules: https://www.cloudflare.com/privacypolicy/ (opens in a new tab)

What the program does not do

ClipSD does not send information about how the program runs or crashes and collects no installation identifiers. The program goes online only for translation (when you press the button), for updates (section 3) and with a rating, if you press "Send" yourself (section 4).

What stays on your computer

  • Settings, including the e-mail for MyMemory: the file config.json in the folder ~/.config/clipsd (Windows: %APPDATA%\ClipSD). Versions 1.29 and older kept it in .config/clipshot; on the first start of 1.30 or newer it is copied to the new folder, the old copy stays.
  • The Google Cloud key and the counter of characters translated: in the same folder. On Linux the key file is readable only by you.
  • The counters of days of use and of screenshots for the rating window and the marks of how often this window was shown: in config.json. The same file holds the stars and the day of the rating you sent (for the "You have already rated ClipSD" window).
  • A rating that has not been sent yet (no internet): in the rating-outbox folder next to config.json, until it is sent (section 4).
  • Update service files (the downloaded version while it is being installed, the startup marker, the result of the last update): on Linux ~/.local/share/clipsd and ~/.local/state/clipsd, on Windows %LOCALAPPDATA%\ClipSD.
  • Screenshots: a folder inside Downloads (Windows Downloads\Screenshots, Linux Downloads/Screenshots) or the one you chose in the settings.

When you uninstall the program, the settings and screenshots stay unless you asked to delete them (on Windows a tick in the uninstaller, on Linux the --purge option). The update service files are removed together with the program.

Your rights

You may ask what data about you the author has, get a copy, correct, delete, restrict processing and object. Until you write to the author yourself or send a rating, the author has no data about you: without your command the program sends the author nothing. If you have written, write from the same address to clipsd.app@gmail.com; you get an answer within a month. If you sent a rating, write the date and the text of the rating (section 4): the author has no e-mail address and no installation number for it, so a rating cannot be found in any other way. For data held by the translation services, ask MyMemory and Google using the links above.

You can also complain to a supervisory authority: in Bulgaria the Commission for Personal Data Protection (https://www.cpdp.bg (opens in a new tab)), or the authority of your country.

Children

ClipSD is not made for children. If you are under 16, enter an e-mail for translation and write to the author only with your parents' permission.

Changes

A new version of this policy is published on this page with a new date. If the program starts sending anything else, the policy changes in the same release.
